# 2x2 UPA receiver configs

Six new confs, one per (receiver, bandwidth), giving each passive receiver a **2x2 square planar
array** instead of the 4-element λ/2 ULA in the base confs:

| bandwidth | rx1 | rx2 | rx3 |
|---|---|---|---|
| 106 PRB / 40 MHz, fc 3319.68 MHz, s = 0.045 m | `ue.passive.upa.conf` | `ue.passive2.upa.conf` | `ue.passive3.upa.conf` |
| 273 PRB / 100 MHz, fc 3.75 GHz, s = 0.0399 m | `ue.passive.upa.100mhz.conf` | `ue.passive2.upa.100mhz.conf` | `ue.passive3.upa.100mhz.conf` |

Each was **generated by transforming its ULA counterpart**, so everything else — receiver position,
scene, cell/CORESET/CSI-RS parameters, CFAR settings, output paths — is byte-identical. A ULA-vs-UPA
run is therefore a controlled A/B in which only the array geometry differs.

## What changed, and why

Element layout is a square of side `s`, `"0,0;s,0;0,s;s,s"`, with `rx_array_boresight_deg = 0.0` and
**no** `aoa_broadside_deg`.

- **Kills the mirror ambiguity structurally.** `isac_aoa.cc`'s `parse_rx_array()` calls an array
  collinear when its max perpendicular spread is below λ/8; a square's is `s/√2` (0.354λ at s=λ/2),
  far above, so `aoa_estimator`'s constructor takes the non-collinear branch and scans the full
  −180..180°. A linear array instead scans only the half-plane `aoa_broadside_deg` faces, and
  getting that wrong is exactly what mirrored every rx2 bearing in the 3-receiver run
  (`PHASE3_AOA_MULTISTATIC_HANDOVER.md`) — a whole class of silent misconfiguration disappears.
- **`aoa_broadside_deg` is deliberately absent, not forgotten.** It is only read in the collinear
  branch; setting it on a square array would be silently inert.
- **Boresight is pinned to 0.** It is a rigid rotation of the element coordinates into ENU. A square
  has 90° rotational symmetry and the scan is full-circle, so no rotation carries information —
  pinning it removes a way for the `[sensing_channel]` and `[sensing]` copies to disagree.
- **Spacing is set from the MIN inter-element gap, which is the side, not the diagonal.** Both
  `isac_aoa.cc` and `sensing_channel.c` flag ambiguity on the minimum gap, so a λ/2 square is
  unambiguous and its 0.707λ diagonal is expected and harmless. Verified numerically per file:
  min gap 0.0399 m vs λ/2 = 0.039972 m (100 MHz), 0.045 m vs 0.045154 m (40 MHz) — both just under.

## The trade-off — read results with this in mind

The square spans only **0.5λ per axis**; the 4-element ULA it replaces spanned **1.5λ**. Bearing CRB
scales with aperture, so expect roughly **3× worse bearing precision** than the ULA on a target the
ULA was already aimed at correctly. The UPA buys unambiguous 360° coverage and immunity to a
mis-set broadside — **not** accuracy. It is also worth remembering that AoA does not reject ghosts:
a harmonic/ridge ghost shares its parent's wavefront and hence its bearing.

## How to run them

Directly, no script change needed:

```bash
nr-uesoftmodem -O tests/passive_rx/ue.passive.upa.100mhz.conf --rfsim --passive-rx \
  -C 3750000000 -r 273 --numerology 1 --band 78 --ssb 1478 --ue-nb-ant-rx 4
```

`--ue-nb-ant-rx 4` is mandatory — `aoa_enable`/`rx_array` alone are silently inert without it (a
one-shot warning fires).

### Pending one-line wiring into `run_passive_rx.sh`

Not applied yet: a comparison batch was running when these were written, and editing a running bash
script in place can corrupt its execution. Apply when idle. Report paths were deliberately left
identical to the ULA confs, so `ALL_RX_REPORTS` needs no change and this is the whole patch:

```diff
 RX1_NANT="${RX1_NANT:-4}"
+# ARRAY=ula (default) | upa -- selects the 4-element ULA confs or the 2x2 square ones (README.upa.md)
+ARRAY="${ARRAY:-ula}"
+[ "$ARRAY" = "upa" ] && A=".upa" || A=""

 if [ "$BW100" -eq 1 ]; then
-  ALL_RX_CONFS=("ue.passive.100mhz.conf" "ue.passive2.100mhz.conf" "ue.passive3.100mhz.conf")
+  ALL_RX_CONFS=("ue.passive${A}.100mhz.conf" "ue.passive2${A}.100mhz.conf" "ue.passive3${A}.100mhz.conf")
 else
-  ALL_RX_CONFS=("ue.passive.conf" "ue.passive2.conf" "ue.passive3.conf")
+  ALL_RX_CONFS=("ue.passive${A}.conf" "ue.passive2${A}.conf" "ue.passive3${A}.conf")
 fi
```

Then `ARRAY=upa BW100=1 NUM_RX=3 NUM_UE=3 ./run_passive_rx.sh 900 /tmp/upa_test`.
