# T4 — receiver CFR gating by API source

## Changes

- [CODE-READ, DGX aarch64] The blind PDSCH monitor accepts either legacy DM-RS source bit for its one receive tap. `pdsch_dmrs` now requests channel estimation and submits its CFR through the enabled source bit; `pdsch_dmrs_blind` retains its distinct adapter bit. The decode cap still skips estimates without a DM-RS consumer. When only the receiver SNR gate needs the estimate, it no longer packs CFR IQ or RE indices.
- [CODE-READ, DGX aarch64] SSB, CSI-RS, PUSCH DM-RS and DL/UL data-aided taps use the API source predicate directly. CSI-RS receiver monitoring remains controlled by its own monitor config. Sinkless CFR counting and `cfr_antennas` stay in the S2b adapter.
- [CODE-READ, DGX aarch64] The DL data-aided G/RE-model validity check remains ahead of its source predicate because `test_nr_ssb_rate_match_prod` validates its refusal count independently of sensing. CFR reconstruction still starts only after the source check.
- [CODE-READ, DGX aarch64] Added `nr_sense_gating_test.cc` and a small blind-monitor predicate fixture. The frame tests cover the six API source IDs, four-antenna IQ order, single-antenna cap and sinkless counting. The blind-monitor tests cover disabled and enabled DM-RS chest/cap decisions.
