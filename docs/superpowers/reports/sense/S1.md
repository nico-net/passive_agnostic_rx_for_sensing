# S1 — sensing export core

## Changes

- `openair1/PHY/NR_UE_TRANSPORT/nr_sense_api.h`: versioned CFR API, source identifiers, configuration and counters.
- `openair1/PHY/NR_UE_TRANSPORT/nr_sense_api.c`: preallocated CFR and JSON Lines rings, one draining writer, drop counters, bounded record copies, binary little-endian CFR v1, optional ZeroMQ `cfr`/`rec` topics, and deterministic test hooks.
- `openair1/PHY/NR_UE_TRANSPORT/tests/nr_sense_api_test.cc`: the seven named Task 1 tests.
- `CMakeLists.txt`: standalone API library and `test_nr_sense_api`, with optional libzmq.

## Decisions

- CFR header length is 48 bytes. The `k_abs` and `l_sym` arrays are followed by 0–3 padding bytes, then antenna-major interleaved float IQ. `ant_stride` counts complex RE.
- An accepted frame keeps its ring slot until file write and optional mirror send finish. Producers drop immediately when all slots are occupied. Close drains accepted items and may wait for slow storage, as in `nr_passive_obs`.
- A single write is attempted per CFR frame or JSON line. Short or failed writes increment `io_errors`; no writer retry can hold up a producer.
- Files are replaced on each successful open. The API module is compiled in both sensing build modes; the receiver adapter is Task 2.
