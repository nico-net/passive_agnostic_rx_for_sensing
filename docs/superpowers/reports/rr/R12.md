# R12 — offline mid-stream reconfiguration replay

Host: DGX Spark (`spark-74c3`, aarch64). Branch: `rr/w3-replay`. Prerequisite R12a: `d0d8cb98c2`.

## Changes

- [IMPLEMENTED, OFFLINE VERIFIED] `nr_reconfig_replay_test.cc` replays real polar-encoded DCI 1_1 grants through the blind raw decoder and length sweep, and synthetic PDSCH CRC outcomes through the existing Technique D sweep. It injects a 47→51-bit DCI length change at slot 2000 or a six-RB-group CORESET move at slot 2400. Each has a SIB1-available and `ISAC_TD_IGNORE_SIB1=1` arm. The fixture runs at mu=1 and 200 grants/s, measures recovery to LOCKED/VERIFIED/converged, and enforces the 10 s (20,000-slot) soft budget.
- [IMPLEMENTED, OFFLINE VERIFIED] Every arm first converges on the old configuration. The SIB1-less arm uses verified TC-RNTI/RAR and recurring persistence evidence while SIB1 publication and epoch input remain inert. Each injection submits an old work ticket after the change; the fixture counts new-context passes and trials credited by that ticket, plus epoch drops. For hard changes it also requires a new Technique D generation, preventing an unchanged old winner from counting as recovery.
- [IMPLEMENTED, COMPILE VERIFIED ONLY] `hidden_reconfig_schedule.h` is a shared deterministic schedule for the replay and `hidden_waveform.h`. The transmitter can emit a truth record and change one UE's dedicated DCI size, move its CORESET, change the SIB1 TAC, or change PCI at the named slot. `ISAC_HIDDEN_RECONFIG` enables the selected injection only with `ISAC_RECONF=1`; `ISAC_TD_IGNORE_SIB1=1` suppresses SIB1 broadcast in the SIB1-less waveform arm. The `nr_dlsim` target compiled. Generated IQ was not run or decoded in this task because simulator campaigns are deferred by `CODEX_BRIEF.md`.
- [PENDING R10] Four hard-change cases retain the 30 s (60,000-slot) assertion and are named `DISABLED_...` with comments naming R10: SIB1 semantic change and PCI change, each with SIB1 available/absent. R10's Technique D epoch consumer is not on this branch. A forced run of `DISABLED_Sib1SemanticChangeSib1Available` failed the new-generation recovery assertion as expected while the old-epoch work was dropped. These cases must be enabled after R10 is integrated; R12 does not implement R10.
