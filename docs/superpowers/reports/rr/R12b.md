## Changes and decisions

- [IMPLEMENTED, OFFLINE VERIFIED] `nr_reconfig_replay_test.cc`: The SIB1-absent TAC change now asserts the old Technique D generation remains, with no epoch bump and no stale drop. Spec §4.6 excludes SIB1 semantic evidence in the absent column; this fixture changes only TAC, so there is no dedicated change to recover from. This arm is enabled. The SIB1-available semantic change and PCI arms still need R10 consumers and remain disabled.
- [IMPLEMENTED, OFFLINE VERIFIED] Stale feedback checks now read counters for the old ticket's `old_key`. A queued work guard with a deliberately stale stamp rejects feedback for local DCI length and CORESET changes; a real prior epoch stamp is used for epoch changes. This specifically validates the guard and old-context counters. It does not claim local changes alone invalidate all same-epoch old work; that is a separate receiver contract.
- [IMPLEMENTED, OFFLINE VERIFIED] `accepts()` requires the actual CORESET group. DCI length's activity hint comes from accepted decoded grants recorded through the receiver's bootstrap API, not a constant SIB1-arm value. The never-set C0 flag and fixture-populated CFRA flag assertions were removed; neither represented actual decoded C0 or RAR traffic. The absent arm checks the receiver C0 USS API directly.
- [IMPLEMENTED, OFFLINE VERIFIED] `nr_passive_cfg_epoch.{c,h}` caches `ISAC_TD_IGNORE_SIB1` with `pthread_once`; a test-only reset hook lets the two test binaries switch arms safely. Replay and touched cache tests restore their prior environment variables with RAII even after a fatal GoogleTest assertion.
- [REVIEWED] `hidden_waveform.h` already uses `%ld` for `physCellId`. The generated `NR_PhysCellId_t` is `long`, so the conversion is correct and was retained.
