## Changes and decisions

- [CODE-READ] `nr_pdsch_config_sweep.c` routes fieldbook transitions through the existing drained R7 sweep listener. Initialisation/reset subscribes before use and starts an empty fieldbook at the central snapshot's epoch/identity. Each callback mirrors its ordered snapshot; after drain the fieldbook epoch equals `nr_cfg_epoch_current()`. Queued older callbacks cannot roll it back. HARD_RESET clears all old-identity fields and advances the fieldbook generation.
- [CODE-READ] With `ISAC_RECONF=1`, the old local bump API is a no-op. `executables/nr-ue.c` calls that legacy discontinuity hook only with reconf disabled. The fieldbook helper `nr_td_fieldbook_bump_epoch()` is reached at runtime only from the central listener when reconf is enabled. The pure fieldbook module and its legacy local-epoch behavior are unchanged.
- [CODE-READ] R11 explicitly says promoted fields lose their ordering bonus. The merged BC4 behavior instead preserves an ordering hint. Central bumps therefore clear the hint as well as support/pruning, only under reconf; flag-unset BC4 retains its hint. Re-promotion still needs two independent new-epoch supporters. Technique D's separate R10 previous-winner VERIFY hint is unaffected.
- [CODE-READ] Before a pending callback drains, the epoch/identity mismatch suppresses fieldbook pruning and convergence votes. This covers new-epoch work reaching the sweep before the reader drains notifications; callbacks are never drained under the sweep mutex. R10's lazy context synchronisation no longer resets the fieldbook independently.
- [CODE-READ] `nr_pdsch_config_sweep.h` documents legacy versus central ownership. The sweep tests adapt the old `EpochBumpDropsBonus` assertion to the real central owner and add multiple-bump/local-hook/reset and pending-drain/HARD_RESET coverage. CMake registers `test_nr_fieldbook_epoch` with `ISAC_RECONF=1`.
- [CODE-READ] With ISAC_RECONF unset, fieldbook=2, GrantWork, CB0 elimination/backend auto, and acquiring-TB CPU defaults are unchanged. No decoder, scheduler, GPU dispatch or configuration default changed.
