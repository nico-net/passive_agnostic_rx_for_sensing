Host: DGX aarch64. Branch: `rr/reconfig-robustness`. Scope: R4 only.

## Changes and decisions

- [OFFLINE VERIFIED] `nr_pdcch_dci_length_sweep.{h,c}` stores `found[2]`, recent-accept slots, and a separate layout pin and cursor for each length. A third significant length replaces the least recently accepted slot; an accepted grant refreshes that slot. The existing `found[0]` path retains its previous behavior when `ISAC_RECONF` is unset or 0.
- [IMPLEMENTED, NOT VALIDATED on live reconfiguration] `nr_pdcch_blind_monitor_rt.c` continues bounded DL and UL length sweeps for locked RNTIs with `ISAC_RECONF=1`. It excludes both locked lengths while seeking another significant result, schedules both locked lengths per RNTI, and updates recency on accepted grants. A replacement reopens DL Technique D. DL layout selection uses the length context's own pin and cursor under the existing length lock; the default path still uses the prior per-RNTI pin.
- [OFFLINE VERIFIED] `tests/nr_pdcch_dci_length_sweep_test.cc` adds `SecondLengthAdded`, `ThirdLengthReplacesLeastRecent`, and `LayoutPinPerLength`. `CMakeLists.txt` links the pin implementation into this focused test target.
