# R1 — DCI payload bit-vector type

## Changes

- `openair1/PHY/NR_UE_TRANSPORT/nr_dci_bits.h`: added the 140-bit, three-word payload type and field, equality, and hash helpers. The header documents low-word-first packing and the existing decoder's 64-bit limit.
- `openair1/PHY/NR_UE_TRANSPORT/tests/nr_dci_bits_test.cc`: checks all legacy 47-bit fields of width 1–16, bits and fields across word boundaries in a 140-bit payload, equality, and hash behavior.
- `CMakeLists.txt`: registers `test_nr_dci_bits` and adds it to the `tests` target.

## Decisions

- [IMPLEMENTED, NOT VALIDATED beyond offline tests] Payload bit zero is the last payload bit, in `w[0]` bit zero. `msb_pos` is measured from the first of `len` bits. The upper words follow the same low-word-first convention used by polar information extraction. `polar_decoder_int16` currently asserts `A <= 64` and writes only `out[0]`; widening that decoder is R2.
- [IMPLEMENTED, NOT VALIDATED beyond offline tests] Invalid field ranges return zero. The hash includes the payload length and only the declared payload bits, so spare high bits do not affect it.
