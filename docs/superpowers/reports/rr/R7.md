# R7 — single cell configuration epoch authority

Host: DGX aarch64 (`spark-74c3`). Branch: `rr/reconfig-robustness`. Scope: R7 only.

## Changes and decisions

- [OFFLINE VERIFIED] `openair1/PHY/NR_UE_TRANSPORT/nr_passive_cfg_epoch.{c,h}` adds the CPU state machine. A mutex protects evidence and subscriptions; atomic reads expose the epoch and identity generation. First identity, MIB and SIB1 observations establish baselines. Changed identity increments `identity_gen` and clears prior cell evidence; MIB and SIB1 semantic changes are hard re-verification. Continuity loss is logged under its own cause. BWP, confirmed CSI-RS map change and two distinct converged RNTI reopenings are soft causes.
- [OFFLINE VERIFIED] The header declares `note_sib1` for any decoded SIB1, on SA or NSA, without requiring it. `CSIRS_MAP_CHANGE` is included from current spec §4.4. SI-modification announcements wait until the next modification-period boundary. An observed changed semantic hash bumps then; an observed unchanged hash does not. If no SIB1 is re-acquired, the default is a conservative boundary bump; `ISAC_RECONF_SI_BUMP_WITHOUT_SIB1=0` disables that fallback. `nr_cfg_epoch_set_slots_per_second()` converts the two-second converged-RNTI window to the cell's slot numerology (default 1000 slots/s until R8 sets it).
- [OFFLINE VERIFIED] `openair1/PHY/NR_UE_TRANSPORT/tests/nr_passive_cfg_epoch_test.cc` and `CMakeLists.txt` add the named R7 tests and two extra boundary checks: 16/16 pass. Duplicate listener subscriptions are ignored and callbacks run once per bump after the state lock is released.
- [IMPLEMENTED, NOT VALIDATED on live traffic] The module is linked only into its test target. R8–R11 will connect trigger sources and consumers. No receiver runtime path or default `ISAC_RECONF` behavior changes in R7.
