# R18b — independent review fixes for R18a and R9

Host: DGX Spark (`spark-74c3`, aarch64); branch `rr/reconfig-robustness`.

## Per-finding outcome

Files changed: `nr_csirs_observer.{c,h}`, `nr_csirs_blind_rt.c`, `nr_pdsch_passive_queue.c`, `nr_pdcch_blind_monitor_rt.c`, `nr_pusch_passive_decode.c`, `nr_passive_metrics.{c,h}`, `nr_passive_metrics_json.c`, and focused fixtures under `openair1/PHY/NR_UE_TRANSPORT/tests/`.

1. **Startup CSI-RS map bump — confirmed, fixed.** [OFFLINE VERIFIED by source inspection] The observer treated any active resource of the same type as a previous map, and retired resources with matching geometry even when their period or offset differed. Confirmation now retains coexisting resources and counts as replacement only after a same-type resource has disappeared under the four-period rule and no same-type resource remains active. `symb_l0` is part of the resource key and confirmation telemetry. ZP revocation uses the exact key captured before bank mutation. A first or late coexisting confirmation cannot emit `CSIRS_MAP_CHANGE`.
2. **Non-occasion misses and ZP isolation — confirmed, fixed.** [OFFLINE VERIFIED by source inspection] The old score path called `observer_due` on any scored slot, and NZP rechecks entered ZP maintenance. NZP misses are now eligible only when `nr_csirs_blind_occurring()` predicts that candidate in the current slot. Scores of 2.0–4.0 are inconclusive: 4.0 remains the NZP confirmation bar, while only scores below 2.0 count as misses. The NZP recheck exits after correlation and observer feedback, without ZP feed, probation, revocation, or discovery state changes. K9 still needs a live OCUDU bed.
3. **Observer flag-off cost — confirmed, fixed in the find path.** [OFFLINE VERIFIED by source inspection] Lookup now stops at the first unseen append-only entry. Observer candidate and confirmation records remain under `ISAC_RECONF=0`, because R18a's `ISAC_METRICS` counters and per-resource confirmation latency consume them; removing that work would silently remove requested instrumentation. Occasion-miss bookkeeping is disabled when reconfiguration detection is off.
4. **PDSCH group copies — confirmed, fixed.** [OFFLINE VERIFIED by source inspection] Epoch filtering and in-place compaction run only when `nr_cfg_reconf_enabled()`. Flag-off groups keep the dequeued jobs directly; flag-on filtering still counts each dropped member.
5. **BWP probe credit — confirmed, fixed.** [OFFLINE VERIFIED by source inspection] `nr_pdcch_bwp_probe_result()` checks the work epoch before and after acquiring the BWP mutex when reconfiguration is enabled.
6. **Inline PDCCH straddles — confirmed, fixed.** [OFFLINE VERIFIED by source inspection] In-line occasions used the scan queue's epoch-drop counter. They now use `pdcch_inline_drop_epoch` in `ISAC_METRICS`; the existing `scanq_drop_epoch` name and meaning are retained for queued work.
7. **PUSCH stage marker — confirmed, fixed.** [OFFLINE VERIFIED by source inspection] The stale-epoch return after UL decode now clears the one-shot stage marker.
8. **CSI-RS threading — confirmed, guarded.** [OFFLINE VERIFIED by source inspection] `nr_csirs_blind_rt_slot()` runs from `UE_dl_processing`, which can be dispatched to multiple DL actor workers, while rate matching is read by decode workers. One mutex serializes the blind state and observer mutations with the export reader; the decoded-grant evidence queue retains its own mutex.
