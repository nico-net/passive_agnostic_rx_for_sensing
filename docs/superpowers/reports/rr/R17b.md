# R17b — independent review fixes for R17 and R18 step 6

Host: DGX Spark (aarch64), branch `rr/w2-uectx`.

## Changes and decisions

- [CODE-READ; OFFLINE VERIFIED, DGX unit tests] `nr_passive_ue_ctx.c` now infers a UE reconfiguration only from a change between two currently TRUSTED values. `TD_STATE` and `DCI_LEN_STATE` remain change-log facts, never reconfiguration evidence. A reconfiguration without a valid absolute slot remains in JSON but cannot feed the cell epoch detector as slot zero. This fixes false two-RNTI SOFT epochs from CRC-loss relearns. The existing epoch-hint contradiction test now expects a change event without a UE reconfiguration, in line with spec §4.7.
- [CODE-READ; OFFLINE VERIFIED, DGX unit tests] All three length-SUSPECT hooks in `nr_pdcch_blind_monitor_rt.c` call the epoch owner whether the UeContext writer is open or closed; UeContext only records the state. The accept hook records UL length only for DCI 0_1 and records CORESET/PDCCH scrambling ID only on dedicated USS 0_1/1_1 accepts. Bank removal and accepts share one CORESET packing helper.
- [CODE-READ; OFFLINE VERIFIED, DGX unit tests] Parameter, RAR-anchor and CSI events refresh UE activity. The writer uses a direct RNTI-to-active-entry index and runs the 1024-entry age sweep at most once per second. Its bounded MPSC ring and disabled-by-default hook behavior remain. The open/close producer handshake uses one sequentially consistent order so the writer cannot free the ring while an entering producer still has access.
- [CODE-READ; OFFLINE VERIFIED, DGX unit tests] `nr_passive_ue_ctx.h` and `uectx_report.py` label CSI-RS evidence as a **coincident resource in the trigger slot**; no CSI request-to-resource linkage is inferred. The offline report test parses `fixture_writer.jsonl`, generated by the C writer test.
