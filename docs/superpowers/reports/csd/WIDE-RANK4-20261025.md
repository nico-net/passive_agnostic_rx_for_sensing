# Wide rank-4 PDSCH on the sens4 lab cell: in-slot SFO (fixed) and 4x4 conditioning (open), 2026-10-25

Host sens6 (x86, RTX), X410 327B872 UC_200, 4 RX, `--ue-rxgain 36`. Cell: sens4 OCUDU gNB, n78 3450 MHz, 273 PRB, SCS 30, 4T4R,
2 phones, gNB max_rank 4, qam256, max MCS 25. Branch `sens6/ota-20261024`. All numbers come from this host and this cell, and are
not to be pooled with other hosts, cells or bandwidths.

## Symptom

Rank-4 CRC falls from ~0.65 at 5-32 RB to 0.03-0.15 at 33-64 RB and to 0 above ~96 RB. The decision-directed post-equaliser
"snr" (EVMGRANT) still reads 24-27 dB, so the SNR looked ample. `[MEASURED, g36_lab_20261025_105941 / _112021]`

That EVM is decision-directed: for 256QAM it saturates at 23-26 dB and cannot show a lower SINR. It is not evidence of an ample
SNR `[CODE-READ, nr_dlsch_demodulation.c EVM block]`.

## 1. In-slot sampling-clock drift: root cause, fixed

- Evidence `[MEASURED, cbmapcpu2_lab_20261025_155639, CBMAP diagnostic, removed since]`: the raw DM-RS symbol-difference SNR is
  computed per 16-RB bin from the first and last DM-RS symbol, with no smoothing and the grant's common phase removed. Narrow
  grants read 33.9 dB. 273-PRB grants read 14.7 / 18.3 / 24.6 / 29.4 / 22.5 / 17.3 / 15.1 / 12.5 / 10.2 dB per 32 RB: the phase
  error grows linearly with |k|.
- Cause: the receiver clock is fast by eps = +3.8 ppm. The timing loop gives +3.77..+3.84 ppm; the PDSCH DM-RS phase slope, measured
  uncorrected, gives +3.78 ppm `[MEASURED, sfooff_lab_20261025_165007, sfokoff_*]`. The loop corrects once per frame, so inside a
  slot symbol l is eps*n_l samples off.
- Fix (commits 6859f63e2e, 4a1e19f8ac, 176afaf312, 84d2a1f46a, 333701f996): one eps provider (`nr_sfo_state`) fed by the timing
  loop and cross-checked by the DM-RS slope. Every DL FEP (CPU, GPU exact FEP, GPU pass; bit-exact twins) multiplies subcarrier k of
  symbol l by exp(+j 2 pi (k - k_ref) eps n_l / N), with k_ref the SSB centre: the receiver's CFO is measured there and already
  contains eps*f_ssb.
- Result `[MEASURED, sfok*_lab_20261025_17*, 2 ON vs 2 OFF alternated]`: raw aligned DM-RS SNR 32-34 dB at every bin of wide
  grants. Slope residual 0.000 ppm. Common term at DC +13/+51 Hz vs -245/-89 Hz without the fix. Rank-4 CRC: 33-48 RB
  0.39/0.29 vs 0.05/0.24; 49-64 RB 0.24/0.17 vs 0.006/0.078; 5-32 RB unchanged or better; >96 RB still ~0. One OFF run (173521)
  was degraded overall and inflates the gap.

## 2. 4x4 channel conditioning: the dominant limit above ~64 RB, open

Diagnostic run `pred_lab_20261025_175817` (CBMAP, CPU paths, SFO on; ONE run). The diagnostic is not in the tree.

| Rank-4 width | CRC (logged grants) | measured DD-EVM SNR | predicted ZF mean-error SNR | predicted ZF capacity-eq SNR | MMSE (correct noise) capacity-eq |
|---|---|---|---|---|---|
| 1-4 RB | 0.95 | 25.8 dB | 24.1 dB | 24.8 dB | 24.8 dB |
| 5-32 RB | 0.85 | 28.3 dB | 24.9 dB | 25.3 dB | 25.3 dB |
| 33-128 RB | 0.12 | 27.1 dB | 13.9 dB | 20.9 dB | 21.1 dB |
| >128 RB | 0.00 | 25.2 dB | 9.0 dB | 16.6 dB | 17.2 dB |

How the prediction is made: the receive noise sigma^2 comes from the DM-RS symbol difference, per RE and antenna, in rx units.
It reads ~35 dB LSB^2, ~10 dB above the empty-RE floor of narrow-grant slots (~25 dB), so it is signal-proportional. With the
chest's H, the per-RE per-layer SINR is ZF P_l / (sigma^2 [(H^H H)^-1]_ll) and MMSE 1 / (sigma^2 [(H'^H H' + sigma^2 I)^-1]_ll) - 1.
The capacity-equivalent SNR is the SNR whose log2(1+SNR) equals the mean over REs and layers.

Reading `[MEASURED, one run]`: the per-layer SINR any linear 4-RX receiver can get from these 4 layers, which are precoded for
another UE, is ~25 dB on the RBs where narrow grants sit. It falls to ~21 dB over 33-128 RB and ~17 dB over the full band, with
nearly singular REs (ZF mean-error 9 dB). MCS 24-25 needs ~25 dB, and one failed code block fails the TB. MMSE with the correct
noise gains only 0.0-0.6 dB, so the linear-receiver headroom is small.

Caveats:
- Noise source unproven `[HYPOTHESIS]`: the signal-proportional noise could be gNB TX EVM (LiteOn RU, compression) or the X410
  (LO phase noise / ICI, ADC). A gain/attenuation check decides it (coordinator).
- The DM-RS difference spans 9 symbols, so it also holds slot-level phase-noise decorrelation the data does not see (nearest DM-RS
  <= 2 symbols away). sigma^2 may be overestimated and the prediction pessimistic by up to ~3 dB `[HYPOTHESIS]`. That does not
  change the >128 RB verdict.
- One run, one receiver position, one cell. The conditioning depends on where the X410 sits relative to the phones' beams.

## What would move it

- Non-linear detection (ML / K-best per RE, or iterative LDPC-aided detection) recovers diversity that ZF/MMSE throws away on
  ill-conditioned REs `[PLANNED]`.
- If the noise is the X410's own (phase noise / ICI), reducing it raises sigma^2-limited SINR directly; the gain check decides.
- Not a fix: tuning MMSE regularisation (<= 0.6 dB here).
