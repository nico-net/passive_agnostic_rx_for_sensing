## Mechanics

* Mechanical rename commits first (`g_` prefix, outside strings/comments, never after `.`/`->`) for `nr_passive_cfg_epoch.c`, `nr_passive_ue_ctx.c`, `nr_passive_replay_capture.c` (generic names `epoch`, `state`, `header`, `output`... would have been rewritten inside struct members and other scopes by the alias macro). The other files already used `g_*`/unique names. No new -Wshadow / -Wpedantic warning in any converted file.
* Every macro use carries a trailing `;` (`NR_CELL_STATIC(T, x);`): without it `static_audit.py` glues the declaration to the following function head and silently drops the object from the table.
* Arrays through typedefs (`g_listeners_arr_t`, `g_sw_arr_t`, `g_sib1_values_arr_t`, `g_active_index_arr_t`, `g_rrc_arr_t`) so all uses `a[i]` are textually unchanged.
* `dci_nr.c` (under active decode work): the diff against mpci-main is one `#include` plus the two block-scope SI census counters (5 lines), no logic, no reformatting.

## Interface additions the other tasks must know

1. **Writer/worker threads are bound to the opening cell.** `nr_core_plan_create` does not bind, so `nr_passive_obs` writer, `nr_passive_ue_ctx` worker and the replay-capture writer receive the opening cell as `arg` and call `nr_cell_bind()` first. Callers must open each cell's session with that cell's thread bound.
2. **Process-wide hints stay global, sessions are per cell.** `nr_passive_obs_fast_open` and `nr_ue_ctx_fast_open` (extern in headers, read by inline `*_enabled()`) are now the OR over cells' open flags. Inside `nr_passive_ue_ctx.c` `nr_ue_ctx_enabled()` is redefined (file-local macro) to mean "this cell's session is open", so a closed cell never touches a NULL ring/entries table. `nr_passive_obs_push` of a cell that never opened is refused without counting an after-close push (N=1 identical except the open()-rollback race window).
3. **`nr_passive_metrics_set_pci(int)`** (new, declared in new `nr_passive_cell_prealloc.h`): writes the calling cell's PCI slot (cell 0 also the legacy global). `executables/nr-ue.c:1210` still stores the global (cell 0 only): **A8 must call the setter** for cells > 0.
4. **Host-global path**: replay capture output goes through `nr_cell_path(nr_cell_idx(), path, ...)` (cell 0 unchanged bytes). The obs/ue_ctx/metrics paths are passed in by the caller (`nr-uesoftmodem.c`, A8: use `nr_cell_path` there). `dci_nr.c` writes the dev fixture `/tmp/pdcch_fixture.bin` (off in production, `nr_pdcch_blind_capture` = 0): left host-global because the file is declaration-only for A3.
5. **Heap objects needing pre-allocation before `nr_cell_alloc_fence()`** (for every active cell, cell 0 included; a first access after the fence is fatal): `nr_passive_reconf_rules_cell_prealloc(cell)` -> `g_rrc_rx`, `g_rrc_eff` (512 KiB each); `nr_passive_ue_ctx_cell_prealloc(cell)` -> `g_active_index` (128 KiB). Declared in `openair1/PHY/NR_UE_TRANSPORT/nr_passive_cell_prealloc.h`. **A8 wires the calls.** Both are first touched by `nr_reconf_reset()` / `nr_ue_ctx_open()` so N=1 tests are unaffected.
