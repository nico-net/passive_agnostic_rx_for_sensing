## N=1 timing-visible changes (host with >= 5 pool tokens) [CODE-READ / HYPOTHESIS]
Float workers run on a pool core only while leased (otherwise on the inherited home mask); their work now queues behind SCAN/DECODE/RETRY and can be delayed or shed under overload;
ulBgDisc yields between steps; csirsDisc holds its token during the hook's GPU waits. Decisions per item and log text are unchanged (janon stale check is not added: `nr_admit` is a stub on this base).
