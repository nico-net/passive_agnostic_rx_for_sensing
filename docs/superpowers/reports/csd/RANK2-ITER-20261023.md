## What changed in the code
- `it=` is now real: max OAI numIter over the code blocks (a block that hit the cap reports the cap), plus `itc=` (cap in force) and `its=` (sum over decoded blocks). CPU segment decoder, GPU exact LDPC host and the GPU graph pass (`k_pick`, `ResBlk.it`) all report it. [CODE-READ + MEASURED, DGX replay]
- One cap accessor `nr_pdsch_ldpc_cap()` (`nr_pdsch_ldpc_cap.h`) replaces the five hard-coded 8s and the never-set `ISAC_LDPC_ITERS_AB` thread-local (removed). Test-only override: environment `NR_TEST_PDSCH_LDPC_ITERS` (1..30). Not a product flag, no ISAC_*. All three decode paths (CPU, GPU exact LDPC, graph pass `it_max`) and the CB0 mirror use it.
- GPU honours the cap: the GPU LDPC job takes `max_ldpc_iterations` (snapshots <= 16, so caps up to 17), graph pass `it_max` is checked `<= 17`. Above 17 the GPU path refuses and the CPU decoder runs, so 24 is not a GPU-comparable arm. [CODE-READ]

## Recommendation
Product cap = 16, one value for all cells (committed). Reasons: no loss in any paired comparison beyond noise; gain at 16 is 60-100 % of the gain at 24 and 16 is the largest cap the GPU LDPC runs (<=17 snapshots) without CPU fallback; 24 raised rank-2 big dec_us p99 to 8-9 ms on t923 (CPU path). Cap 12 gives roughly half to three quarters of the 16 gain; take 12 only if the OTA p99 breaks 5 ms.
Early-stop / adaptive: not measured. The decoder already stops at the first CRC/zero syndrome, so extra cap only costs time on blocks that fail; the iteration histogram shows converged blocks end almost all before 8. A syndrome-weight convergence rule is plausible but untested here; a fixed 16 is the measured option. [INFERRED]

## Caveats
- Two captures with usable rank-2 big grants (v415b, t923), 40-340 grants each; v415o has none. Margin estimator is the DD inversion (+-1.5 dB). Edge band n too small to separate.
- Replay grants vary per run; trust paired numbers. Cap 8 vs cap 8 noise is 2-5 grants.
- Unit tests: `test_nr_hq_retry` (cap parse, default 16 <= GPU max, iteration summary) passed.
