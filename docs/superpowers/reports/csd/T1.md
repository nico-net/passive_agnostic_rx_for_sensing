# T1 — U1 slot feed, CRB-aligned ring, and worker skeleton

Host: DGX Spark (aarch64); branch `csd/t1`.

## Outcome

[OFFLINE VERIFIED] The U1 feed is implemented behind `ISAC_CSIRS_DISC=1`, which is read once and defaults off. The ring stores CRB-aligned `[antenna][14 symbols][12*N_RB complex REs]` entries, including copies which wrap at the FFT boundary. A producer uses a try-lock and increments `csirs_disc_feed_drops` instead of waiting while a consumer owns the ring.

[IMPLEMENTED, NOT VALIDATED on replay/OTA] The singleton `csirsDisc` worker owns the configurable ring, optionally pins itself to `ISAC_CSIRS_DISC_CORE`, and wakes on a condition variable every `ISAC_CSIRS_DISC_BATCH` successful pushes. It invokes `nr_csirs_disc_process_hook` while holding the reader lock; the hook intentionally remains null until T5.

The shared `nr_csirs_disc.h` contract was extended additively with synchronization, allocation, worker, and hook declarations. Existing fields and API semantics were not changed.

## Implementation

- `openair1/PHY/NR_UE_TRANSPORT/nr_csirs_disc_feed.c:16-311`: period table; one-shot enable flag; aligned/unified ring allocation; metadata and FFT-wrap copy; nonblocking producer/drop count; explicitly non-RT worker lifecycle, affinity, batching, and process hook.
- `openair1/PHY/NR_UE_TRANSPORT/nr_csirs_disc.h:27-110`: additive U1 ring-private state, read lock, allocator hooks, process hook, counter, and worker API.
- `openair1/SCHED_NR_UE/phy_procedures_nr_ue.c:2410-2430`: after the CSI-RS monitor block, FEPs only symbols absent from `slot_fep_map`, then feeds the running worker with `nr_ue_diag_producer_absolute_slot`, the same monotonic absolute-slot source used by the existing blind search.
- `executables/nr-uesoftmodem.c:468-479,561`: starts the worker after UE/frame initialization and stops it after all slot producers join, including the early file-replay return. Feature-off startup performs no allocation and starts no thread.
- `CMakeLists.txt:994,2835-2840`: adds the feed to `PHY_SRC_UE` beside `nr_csirs_blind_rt.c` and registers `test_nr_csirs_disc_feed`.
- `openair1/PHY/NR_UE_TRANSPORT/tests/nr_csirs_disc_feed_test.cc:12-94`: default-off, one/four-antenna bit-exact FFT-wrap copy, metadata, ring wrap, and locked-reader drop coverage.

Decisions: the ring's mutex is opaque through `private_state`, so downstream units keep the public data layout while the RT producer can use `pthread_mutex_trylock`. Unified storage is obtained through `nr_csirs_disc_alloc_unified` with a paired free hook; absent a GPU hook, the CPU build uses 64-byte `aligned_alloc` and has no CUDA dependency. The worker is ordinary non-RT pthread code; only optional CPU affinity is applied.

## Limitations

- [IMPLEMENTED, NOT VALIDATED with CUDA] CPU fallback allocation is tested. The GPU module must install both unified allocation/free hooks before worker startup.
- [PLANNED] Duty cycling and discovery-completion throttling belong to later integration; while enabled, T1 feeds every processed DL/flexible slot.
