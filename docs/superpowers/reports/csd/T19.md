## Statistic and false-alarm derivation [CODE-READ]

For each snapshot k, ID i and constituent symbol d, use the original maximum
six-RB normalized DM-RS correlation `v[k,d,i]`. Standardize it as
`z = (v - median) / (1.4826*MAD)`, with the original 4096-bin histogram and sigma
floor. The first symbol retains the complete 65,536-ID histogram. Later symbols
use a fixed 1,024-ID panel `{0,64,...,65472}`, chosen independently of any observed
scores. The panel avoids calibrating the null on the selected high-scoring IDs.

For duration D=2/3, define `Z_D = sum(d=0..D-1, z_d)/sqrt(D)`. A snapshot is a hit
iff `Z_D > sqrt(2*log(65536))+2` **and every constituent z_d > 2**. D=1 retains the
original hit rule. The constituent gate prevents a strong duration-1 signal
plus empty symbols from becoming a longer resource. It also permits exact
short-circuiting of this defined statistic: IDs with first-symbol z<=2 cannot
produce a D=2/3 hit, so their later Gold sequences need not be evaluated. A fixed
panel still calibrates each later symbol independently. The sum is noncoherent
across symbols; stage 2 subsequently checks coherent legal bundle geometry.

Let `H[D,s,i]` be the number of these **combined hits**, not a sum of legacy
single-symbol hit counts. For each duration/start family separately,

```
lambda[D,s] = sum_i H[D,s,i] / 65536
F = sum(D=1..capture_duration, 15-D)   # 14, 27, or 39
k[D,s] = smallest positive integer k such that
         F * 65536 * P(Poisson(lambda[D,s]) >= k) < 0.01
```

Separate lambda values account for unequal snapshot counts and duration-specific
null distributions. The sum of expected false cells across all families is
below 0.01; the union bound needs no independence between overlapping duration
hypotheses. This retains the frozen tool's **per-region/per-pass 1% Poisson-model
budget**, rather than assigning 1% independently to each duration. The upper
tail is summed directly from its first term, avoiding `1-CDF` cancellation at
million-cell significance levels. Including real IDs in lambda is conservative
under the same homogeneous-null model.

As in the frozen tool, lambda is estimated from the observed population and
occasion counts are modeled as Poisson. This is **not** a distribution-free
proof for arbitrary structured PDSCH interference or correlated captures. The
negative fixtures check actual outputs; each full-sweep fixture also checks the
summed modeled false-cell budget and minimality of k. These two checks should
not be confused with a large-sample empirical false-alarm measurement.

## Limits and interpretation

- [IMPLEMENTED, NOT VALIDATED ON DEVICE] GPU runtime parity, sanitizer results,
  stage-1 GPU cost and the five-second cooperative production budget are deferred.
- Geometry retains the frozen ambiguity semantics: non-interleaved handoff can
  be a covering superset; L6/R2 can have equivalent shifts (fixture 12 has 12
  tied shifts). A unique shift is asserted only in the identifying R3 fixture.
- The existing AL1-only classification limitation remains. Strong cross-ID
  sequence aliases can still pass the three-decoy geometry check; this is a
  discovery shortlist, not CRC confirmation. Downstream bank/decode verification
  remains required. The mixed fixture checks both planted IDs, not uniqueness.
- The z>2 constituent gate is a deliberate sensitivity/cost tradeoff: a resource
  with a deeply faded constituent symbol may fail this pass. Later-symbol panel
  calibration uses fewer IDs than the first symbol; device parity and broader
  statistical/OTA characterization remain necessary.
- Only windows fully contained in the captured slot can be analyzed. The
  existing duration-3 producer skips starts 12/13; duration 2 at symbol 12 is
  tested with a two-symbol capture. No capture/receiver scheduling changes.
