* Edited beyond declarations: `consumer_arg_t.cell`, `cdmrs_obs_t.cell`, thread start binding (below), `nr_pdsch_passive_harqc_test()` test hook, prealloc entry points, `#include`. No decode logic changed.

## HARQ isolation
DL HARQ soft store, device-block pool and its lock are PER_CELL: the key is (cell, rnti, pid) by indexing. `test_mpci_a5_interleave`: `SameRntiAndHarqIdInTwoCellsNeverCombine` (cell 0 holds a failed first transmission of (0x4601, pid 3); the same retransmission combines in cell 0 and is a first transmission in cell 1, whose store is empty) plus the step-by-step interleave of the store ops.
