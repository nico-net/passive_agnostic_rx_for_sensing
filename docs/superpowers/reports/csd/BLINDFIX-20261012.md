# BLINDFIX-20261012: statistical replacements for cell-fitted constants (audit F1, F3, F5, F6, F7, F8)

Branch `csd/blind-fix` (from `csd/otatest` 9f1930ad4f). Host: DGX Spark aarch64, CPU build, 4 RX. Source: BLINDAUDIT-20261012.md.
Every change is behind its own env flag, **default off** (flag unset = byte-identical decisions). New shared header:
`openair1/PHY/NR_UE_TRANSPORT/nr_blind_stats.h` (exact binomial tail, CFAR score level, co-occurrence, table evidence).

## Mechanisms

| Item | Flag | Replaces | Rule |
|---|---|---|---|
| F8 | `ISAC_SWEEP_SIGNIF=1` | winner needs rate >= 2 % and 3x runner-up (`nr_hyp_sweep.c`, `nr_pdsch_config_sweep.c`) | winner must beat chance (CRC-24 false pass 2^-24) and the runner-up (exact conditional binomial test on the pass counts, p = n_b/(n_b+n_s)), both at 1e-3 / n_active hypotheses (Bonferroni). Early-separation path unchanged. |
| F3 | `ISAC_PDCCH_GATE_CFAR=1` (`_Z`, default 3.09) | 3.0 x running-median energy gate (only when the cfg `noise_gates` enables it) | amplitude-consistency score s = (sum abs)^2/(n sum x^2) has null mean 2/pi, variance (8/pi-24/pi^2)/n; reject when s < mean + z sigma(n). Scale-invariant, per-candidate RE count, no population statistic, cannot reject 100 % of a dense CORESET. |
| F7 | `ISAC_MCS_TABLE_EVID=1` | cfg `mcs_table=1` as default table (also TBS_LBRM table) | DCI 1_1 full-TB CRC passes are counted for every MCS table that reads that MCS to the same (Qm,R) (only when some table reads it differently); sign-test latch at 1e-3 -> table overrides cfg for the default grant table and lbrm table. Technique D / solver already sweep the table per hypothesis; this only fixes the default path. Cell-wide, not per RNTI. |
| F1 | `ISAC_CSIRS_FULL_BLOCK_INFER=2` (1 = old rule) | "every TRS of a 52-RB block co-occurs" | c is inferred into a slot only from a block member a present in it AND (a,c) both occur in >= 2 slots of the 640-slot window of the discovery export (`discovery_cooccur`, `nbs_joint_slots`). No export / no co-occurrence -> only measured resources rate-match. |
| F6 | `ISAC_UL_LOCK_BWP_ALL=1` | BWP hypotheses from a fixed size list, starts <= 5 | after the legacy list (+SIB1 first, order kept) append every legal (N,start) with riv_bits(N) = fitted RIV width and N(N+1)/2 > max observed RIV (an observed RIV makes smaller N illegal, never excludes the truth), N descending, start ascending, up to `NR_UL_LAYOUT_MAX_HYP` (64 -> 192; trial tag hypothesis index 6 -> 8 bits, identical behaviour). Note: audit example "100 PRB at RB 20 of 106" is geometrically illegal; a 95 PRB BWP at RB 10 is the right example. |
| F5 | `ISAC_UL_LOCK_MCS_STAT=1` | `pairs>=64, score>=1.2, margin>=0.3` | best offset needs BOTH the pid-step count (null p = 3/16) and RV0 count (null p = 1/4) significant at 1e-3/#offsets, and must beat the runner-up offset on the pooled success count (a one-bit shift is not the field). Sparse traffic is accepted when significant. |

## Known limits / not done

- F7 is cell-wide, not per RNTI; if every grant is swept the default path is rarely used, so the effect is small by design.
- F6 CRC-first trials still try only the top-K ranked hypotheses; the wide set is exercised through DM-RS votes.
- F1 edits `nr_csirs_disc_confirm_internal.h` (one added read-only helper `discovery_cooccur`); the CSI-RS discovery rate-limit agent owns that file, merge carefully.
- F8 is slower to declare on a link with true rate near 2 % and a runner-up at 0 (needs ~18 passes with 233 hypotheses) than the old 6; it is, however, defined at any rate.
- Not covered: F2 (wsy), F4, F10 (drv), F18, F15, F16, F24.
