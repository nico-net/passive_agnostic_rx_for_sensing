## 2. What changed (all default off)

| flag | effect |
|---|---|
| `ISAC_UL_PRIO_QUEUE=1` | layout probes + CRC-first trials in their own ring (`ISAC_UL_PROBE_DEPTH`, 8); dequeued only when no real grant waits; a probe never evicts a real grant |
| `ISAC_PUSCH_CONSUMERS=n` | lifts the forced n=1 of pipeline mode: one prewarmed context (gNB ctx, snapshot, scratch) per consumer; cores `ISAC_PUSCH_CORES` |
| `ISAC_UL_QUEUE_DEPTH=d` | real-grant ring depth |
| `ISAC_UL_SNAP_POOL=1` | capture thread (`ISAC_UL_SNAP_CORE`, prio PUSCH+1) copies each booked UL slot once (1.1 MB, 4 ant) into a refcounted pool (depth+n+2 buffers, 2 MB each); every job of that slot shares it, so a real grant no longer expires with the one-frame rxdata ring (15-slot limit) while it waits |
| `ISAC_UL_SPARE_RESCUE=1` | UCI explore search and UL_RETRY alternates only when no real grant waits |
| `ISAC_UL_CPU_BUDGET_PCT=p` | per-consumer duty cap (100 ms windows); not needed when the UL runs below PDSCH priority |
| `ISAC_UL_HARQ_COMBINE=1` | UL soft combining: CRC-failed first transmission stores its soft buffer per (rnti, pid); same-NDI same-TBS rv != 0 grant decodes into it; chain mode books rv != 0; first decode call per job only |
| `ISAC_UL_SOLVER_FALLTHROUGH=2` | every solver-path grant without a full decode also gets one ordinary full decode (1 = old non-probe-class only) |

New census line `PUSCHQ2` and `UL_HARQ`. Unit tests `UlqPriority.*` (in test_nr_pdcch_blind_monitor): 2/2 pass `[OFFLINE VERIFIED]`.

## 4. Risks / open

- Root blocker for UL CRC-OK is not capacity: wrong DCI 0_1 layout/BWP lock (csd/ulbwp) and low UL SNR. Decoding every grant
  only pays once the layout is right.
- Little cores 0,1: FEP ~3x slower; 2 little consumers do not cover Vodafone peak. Big cores 8,9 below PDSCH priority cost
  3 ms/grant but share cores with PDSCH and the RT thread pool (8,9,15): DL p99 impact not yet resolved by measurement.
- FEP dominates per-grant cost; next lever: FEP only the grant's PRB band (pruned) or GPU FEP for UL (not started; GPU is shared).
- Not run: full ctest; more DL p99 repetitions; CPU_BUDGET arm; OTA.

## 7. Risks

- UL CRC-OK is gated by the layout lock / RIV and by UL SNR (DM-RS median -7..-11 dB here), not by capacity.
- Little cores cannot carry Vodafone peak load; big cores shared with PDSCH are unproven for DL p99.
- Snapshot pool memory: (depth + consumers + 2) x 2 MB = 72 MB at depth 32; HARQ store <= 64 x 8 x 52 kB = 27 MB.
- HARQ combining CRC benefit unvalidated; a wrong (rnti, pid, NDI) pairing would combine unrelated soft bits (guarded by
  same NDI + same TBS, first decode of a real-grant job only).
- Replay DL numbers after 17:00 come from a contaminated host and are excluded.
