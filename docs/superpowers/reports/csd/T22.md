With CSI-RS discovery unset, the existing fixed-window behavior/cadence remains.
With the GPU feature unset, the legacy receiver/dump behavior remains.

### False-alarm calculation [ANALYTICAL under the inherited null model]

For each duration D/start s, each snapshot contributes one hit iff the T19
statistic passes. Within the current sliding window:

```
H[D,s,i] = sum of retained batch hits for ID i
lambda[D,s] = sum_i H[D,s,i] / 65536
F = sum(D=1..capture_duration, symbols_per_slot-D+1)
alpha_t = 0.01 / (t*(t+1)), t = 1,2,... over all live looks
k[D,s,t] = min k>=1: F*65536*PoissonTail(lambda[D,s],k) < alpha_t
```

Lambda is recomputed from the **incremental combined hit totals**, separately
for every duration/start, after eviction/addition. Since
`sum(t>=1, 1/(t*(t+1)))=1`, the union bound spends at most the frozen tool's 1%
per-region budget over the whole context lifetime, rather than spending 1%
anew on every early look. Overlapping windows/durations need not be independent
for this union bound. This is conservative relative to a single frozen pass.

The inherited Poisson population model and plug-in lambda are **not** a
validity proof for arbitrary structured or temporally correlated interference.
Every-slot samples may be more correlated than T20 samples. Noise/load
fixtures, device parity, and eventual long negative streams are necessary;
no empirical OTA false-record rate is asserted here. Late look thresholds
become stricter; history expiration does not refill the lifetime error budget.
