## Per-cell memory (B.6 item 4, hook for G1) and where A8 calls it
There is no fixed-size big array: the FD ring (`capacity x n_ant x 14 x 24 x N_RB x 2 B`, unified/host + device grid), metadata/locks/serials, the TD sample pool (`nr_csirs_disc_td_bytes(fp, n_ant, capacity)`,
2 MB rounded) + FFT batch buffers, and (lazily, first `detect()`) the detector history `(640 + 80 + 64 + 2) x (168 x N_RB + POOL) x 8 B` are heap blocks allocated at start from the CELL's
`N_RB_DL`, `nb_antennas_rx`, FFT size, under the host-RAM budget. `td` (1.40 MB) is the only `NR_CELL_STATIC_HEAP` object; it is allocated by `nr_csirs_disc_td_init`, and `td_ready()` never allocates
(an inactive cell answers "not ready" even after `nr_cell_alloc_fence()`; tested).

* **Entry point (new `nr_csirs_disc_cell.h`)**: `int nr_csirs_disc_cell_prealloc(int cell, const NR_DL_FRAME_PARMS *fp, int n_ant)` once per ACTIVE cell, **before the RX fence**. It binds the calling
  thread to `cell`, runs `nr_csirs_disc_start`, restores the binding. **A8 must call it** from the cell activation (replacing the single `nr_csirs_disc_start(&disc_ue->frame_parms, ...)` at
  `executables/nr-uesoftmodem.c:583`) with that cell's frame parameters, and `nr_csirs_disc_cell_release(cell)` for `nr_csirs_disc_stop()` (lines 615, 728). Calling `nr_csirs_disc_start()` from a thread already bound
  to the cell is equivalent (cell 0 unbound = today).
* **G1 ledger hook**: `nr_csirs_disc_cell_mem(cell, &m)` returns `{active, n_rb, n_ant, ring_slots, td_slots, ring_host_bytes, td_host_bytes, gpu_bytes}` (real bytes at start); `nr_csirs_disc_cell_host_need(fp, n_ant)`
  is the pure full-size host estimate for the admission model.
* **Host-RAM budget with several cells**: `nr_host_membudget` keeps ONE committed figure per module and `nr_host_membudget_size()` credits the module's whole holding as "own". Each cell therefore records its bytes
  in `cell_ledger` and the module is committed with the sum (`nr_csirs_disc_cell_host_commit`); the fit is `nr_host_membudget_fit_pct(headroom, own_of_this_cell, ...)`, i.e. exactly the old formula at N=1
  (same 30 % ring / 60 % TD / floors 160 / 256, same log lines). The elastic ring in `nr_csirs_disc.c` commits through the same helper. Test: committed == sum of both cells, and after one release only the other remains.

## Threads (unbound-thread sites)
* `disc_worker_main` ("csirsDisc"): **one per cell**, created by `nr_cell_thread_create(.., nr_cell_idx())` inside `nr_csirs_disc_start`; every `g_worker/td/history/...` use inside it resolves to its cell. It calls
  `nr_csirs_blind_rt_discovery_drain()` and `nr_admit_try()` from that bound thread (those modules, owned elsewhere, must use `nr_cell_idx()`; no job struct is involved).
* No process-wide worker touches A7 per-cell state. No GPU host callback / CUDA event thread exists in A7 files (GPU ops are synchronous calls from the cell worker).
* Code that can run on another cell's thread now finds the cell from the ring/argument, not TLS: `nr_csirs_disc_ring_push` and `ring_reset` use `worker_cell_of(ring)` (wake the right worker; `nr_csirs_disc_td_reset_cell(cell)`);
  `nr_csirs_disc_get_metrics_cell(cell, out)`.
* **Sites other tasks must fix**: (1) `nr_csirs_disc_td_push` is called from `phy_procedures_nr_ue.c:1523` (A8: the slot thread must be bound to its cell). (2) `epoch_listener` (registered once via `nr_cfg_epoch_subscribe`) runs on the thread
  that raises the epoch and uses `nr_cell_idx()` for the pipeline state: A3's per-cell epoch authority must raise it on the cell's own thread (ring/TD reset itself is cell-explicit). (3) `nr_passive_metrics.c:241` calls
  `nr_csirs_disc_get_metrics()` (calling thread's cell): the emitter should call `nr_csirs_disc_get_metrics_cell(k, ..)` per cell. (4) `ISAC_CSIRS_DISC_CORE` (`env_core`, `nr_bg_lane_enter`) is process-wide: all cell workers would pin to the same core (B-group lane).

## G-side sites (not implemented; A7 uses the existing `nr_csirs_disc_gpu_ops_t` only)
1. `gpu->prepare(N_RB, n_ant, capacity, fft, stride)` and `gpu->sweep_prepare(rb, ant, cap)` in `nr_csirs_disc_pipeline_init` / `elastic_tick`, and `gpu->reset/detect/accumulate/sweep/refine/confirm`: the GPU module keeps ONE workspace; a second cell with another N_RB re-prepares it. Needs per-cell workspace keyed by the cell (or by the ring) behind `nr_gpu_cell.h`.
2. `nr_gpu_membudget_commit(NR_GPU_MEM_CSIRS, bytes, scale)` replaces the module figure per call (same "one figure per module" issue as the host budget); A7 records `gpu_bytes` per cell (`nr_csirs_disc_cell_note_gpu`) for the G1 ledger to sum. `nr_gpu_membudget_dyn_acquire/release/abort` in `elastic_tick` are additive already.
3. `nr_csirs_disc_gpu_disable()` / `g_gpu_disabled` and the circuit breaker are process-wide (one device): a GPU preallocation failure of cell k disables GPU discovery for all cells until G gives per-cell GPU state.
4. Detector history `history_alloc` uses `nr_csirs_disc_alloc_unified` (cudaMallocManaged) lazily at the first detect of the cell, i.e. possibly after the RX fence (unchanged from N=1 today); G/A8 may warm it before the fence.
