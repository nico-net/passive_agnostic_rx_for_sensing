# T2 — periodic CSI-RS footprints and synthetic grids

Host: DGX aarch64, sandbox without a CUDA device. Branch: `csd/t2`.

## Implementation

- `openair1/PHY/NR_UE_TRANSPORT/nr_csirs_disc_fp.c:26`: antenna-summed, Q12 RE energy contrast, normalized against the same slot/RB's unexcluded REs across symbols, clipped at 2. Pooling symbols keeps dense CSI-RS combs visible. Every candidate compares each RE against its own off-lattice history. Whole-slot comb averages, rather than independent-RE variance assumptions, determine seed confidence under correlated scheduling. At least three observed occasions and three off-lattice slots are necessary; the small-sample confidence penalty usually requires more.
- `nr_csirs_disc_fp.c:93`: folds all 13 periods using absolute slot metadata, estimates combs, searches contiguous extents with a noise-dependent penalty, distinguishes even/odd half-density, merges matching symbols, and suppresses weaker aliases (including non-dividing periods with a common factor). Outputs are sorted by strength and bounded by the public cap. Excluded symbols/REs are absent from both reference and signal statistics. Invalid ring entries are ignored; storage order is irrelevant.
- `nr_csirs_disc_gpu.cu:10`: CUDA normalization, pooled statistics, and per-period integer reductions. The host clustering implementation is shared with the CPU reference. Explicit device copies support ordinary host rings; `cudaMallocManaged`/`cudaFree` hooks support U1 allocation. `libcsirs_disc_gpu.so` is a CUDA MODULE targeting the configured architecture (here sm_121), with `.footprints` populated and `.sweep == NULL`; T4's kernels remain separate.
- `nr_csirs_disc_backend.c:30`: feature-gated, thread-safe loader; `ISAC_CSIRS_DISC_BACKEND=cpu` bypasses loading, `auto`/`gpu` attempt loading, and absence/failure returns NULL. Searches the library path and the executable directory. Successfully loaded modules stay resident to preserve function/allocation lifetimes.
- `tests/nr_csirs_disc_synth.{h,c}`: reusable static test library, independently owns a contract-compatible ring, calls OAI `get_csi_mapping_parms` and `nr_generate_csi_rs` for rows 1–18 and all ports. Seeds random scheduled contiguous RB ranges, QPSK data, type-A/type-1 DM-RS-like combs on symbols 2/11 at 1.9x data power, a 240-subcarrier/four-symbol SS/PBCH-like block every 20 ms, per-antenna flat/slightly sloped channels, and Gaussian noise. PDSCH is replaced on CSI-RS REs, never added underneath. OAI's QPSK table's 1/sqrt(2) amplitude scaling is explicitly compensated; a separate test checks the requested 1.2 power ratio. The MIMO fixture uses a dominant first port per CDM group and weak nonzero cross ports.
- `tests/nr_csirs_disc_fp_test.cc`: four-antenna recovery, period-prefix measurements, calibrated weak-pilot OTA geometry, no-pilot controls, exclusions, multiple resources, reversed/missing ring entries, generator reproducibility/validation, and CPU/CUDA output equality including managed memory when a device exists.
- Root `CMakeLists.txt` links the CPU detector/loader into PHY_NR_UE and exposes `nr_csirs_disc_synth` and `test_nr_csirs_disc_fp`; CUDA target wiring is in `openair1/PHY/CODING/CMakeLists.txt`.

The header changes are **additive only**: `<stddef.h>` for standalone inclusion and declarations for the CPU loader and module allocator/free hooks. Existing fields and semantics are unchanged. This task adds no receiver hook, thread, or feature-off runtime action.

## Integration details

**T5 must explicitly set `cfg.min_strength = 1.03f` for the weak-pilot mode tested here.** The existing contract's NULL/zero configuration default remains 2.0; changing it was forbidden. Statistical confidence and the absolute ratio floor are separate tests. Strength is the ratio of mean clipped contrasts, not raw RF power or a probability.

T4/T5 can link `nr_csirs_disc_synth`, include its public test header, call `nr_csirs_disc_synth_init()` once, create a ring with `nr_csirs_disc_synth()`, and release it with `nr_csirs_disc_synth_free()`. Test executables supply the usual OAI `uniqCfg` and `exit_function` symbols. U1 should resolve `nr_csirs_disc_alloc_unified` and `nr_csirs_disc_free_unified` from the module and retain the matching deallocator (the GPU test shows `dladdr(ops->footprints)` followed by `dlopen`/`dlsym`; the module is RTLD_LOCAL). The detector assumes an immutable ring snapshot while running.

## Limits and decisions

- A sequence-free energy statistic cannot distinguish equal-distribution, equal-power pilots from continuously scheduled QPSK. The weak case tested here retains a 1.2x power difference. More observations are needed as that difference vanishes.
- **Dot5 has an unavoidable extent ambiguity:** silent endpoint RBs cannot identify the configured start/length. The detector reports the minimal observable contiguous span from the first to the last occupied RB; the synthetic truth helper explicitly canonicalizes to that same span. Exact configured bounds including silent endpoint RBs are not claimed. Full-density bounds are recovered exactly in the tests.
- At least four occupied RBs are required by clustering. The strongest contiguous run is returned for each symbol/comb/parity/lattice; disjoint resources with exactly that same signature are not separated. Same-symbol resources with different overlapping combs can merge; U3/U4 still have to resolve configurations and identities.
- A periodic scheduling pattern can imitate a periodic energy footprint. Structural masks and U4 sequence validation remain necessary. SSB exclusions in these tests come from the fixture's known broadcast location; DM-RS is not blanket-excluded in the recovery/no-pilot tests.
- Synthetic SSB/DM-RS are occupancy/power models, not encoded PBCH or full DM-RS Gold-sequence fixtures. The CSI-RS itself uses the production generator. Channel/traffic models do not establish OTA sensitivity or false-alarm rates.
- A 640-slot ring cannot contain three occasions of P=320/640. Long-period tests use longer rings. Neither a three-occasion universal guarantee nor the end-to-end <5 s goal is established by U2.
- GPU normalization/folding are accelerated; clustering remains on the CPU. GPU throughput, latency, and real-time integration are unmeasured.
