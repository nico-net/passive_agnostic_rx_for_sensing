# Scan tail (PDCCH scan p99), 2026-10-17

Sonnet agent; saved by the orchestrator. csd/int16-gprio = csd/int16 7a08e306e4 + 7478c4ebf5 (ISAC_SCAN_READING_HASH=1, default off, bit-exact, unit test). Env ota/t26eE.env, replay CAPSET=b and tim. Labels [MEASURED, DGX replay <cap>, t26eE, n].

## Cause
Scan p99 tail = PDSCH solver DCI 1_1 layout resolution inside the scan thread's post phase, under the Phase-2 lock, plus blocking of the other scan consumer on that lock. Not queueing, not a scan pass, not lazy CUDA load, not page faults, not descheduling (involuntary switches ~0).
- Existing counters (n=1): SCANTIME_FINE b p50 313 / p99 2364 us (over 500 us: 6104 of 20000); tim 250 / 1162. Queueing secondary (~0.1 ms p50, 0.4-0.9 ms p99). BTIM means b: fep_llr 48, decode 31, demap 10, post 72, total 200 us; tim 41/17/11/38/137.
- Slow occasions (> 1 ms, instrumented, b n~3700, tim n=188): b 1.0-1.5 ms bin: run 1211, cpu 1073, Phase-2 wait 39, post 560, solver layout loop 390, solver body 470, parses 1442; > 2.5 ms bin: run 3228, cpu 1958, Phase-2 wait 699, post 2041. tim > 2.5 ms: Phase-2 wait 815, solver body 2375.
- 88 % (b) / 65 % (tim) of slow occasions contain a solver call touching ~4000 (b) / ~1400 (tim) layouts; only ~140 alive on b (reopen_layouts admits dead layouts of live FDRA modes); offset-key table saturated (256) and reading groups (128); ~1770 parses per call on b (~180 us) + ~300 us of linear reading dedupe (nr_dci11_same_reading, up to 128 compares per parse). perf: nr_dci11_same_reading ~10 % of scan-thread samples.
- tim extras: DL length sweep worst cases 5.7-7.2 ms; first-touch minor faults (2000-4300) in a few occasions.

## Fix
ISAC_SCAN_READING_HASH=1: open-addressing index (nr_dci11_reading_idx_* in nr_pdcch_blind_monitor.h) replaces the linear dedupe; chain verified with nr_dci11_same_reading so the match equals the linear search. Unit test ScanTail.ReadingIndexMatchesLinearSearch (40 rounds, with/without rv/ndi/harq compare). Files: nr_pdcch_blind_monitor.h, nr_pdcch_blind_monitor_rt.c, tests/nr_pdcch_blind_monitor_test.cc.
