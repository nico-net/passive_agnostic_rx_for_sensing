## Implementation

- `nr_csirs_disc_win_t` gains `noise_mu`, `noise_sigma`, and `noise_count` at the end. Existing fields,
  candidate scores, deterministic winner selection and different-ID runner-up semantics are preserved.
  These are **population** moments of the occasion-averaged scores for every other ID/delta candidate;
  all delta variants of the winning ID are excluded. A single-ID search or empty lattice has zero count
  and zero moments. Zero-energy input with other IDs and a nonempty lattice has zero moments and the
  usual candidate count. Core and GPU modules must be rebuilt together because the result stride grows.
- CPU `nr_csirs_disc_sweep_winner` accumulates shifted sums and squared sums in double. Subtracting a
  retained candidate as an origin avoids cancellation even for nearly constant distributions.
- CUDA averages occasions in double, then a 256-thread CTA reduces the global winner, different-ID
  runner-up, and shifted double sums/squares. Only the result returns to the host. Ties retain ascending
  ID/delta order. Empty-lattice results still use the common host helper.
- `nr_csirs_disc.c` uses `nr_csirs_disc_gate_internal.h` for both initial admission and the full sweep
  after extent refinement: `z >= mu + K*sigma && z-z2 >= M*sigma && z >= floor`.
  The pooled history and warm-up fallback are removed. Coarse CPU screening results cannot be admitted.
  Configuration is read once per batch; invalid/nonfinite values fall back to defaults. Nonnegative
  K/M values are supported. Missing/invalid moments cannot pass the adaptive rule.
- Positive `ISAC_CSIRS_DISC_WIN_Z` explicitly restores the legacy fixed-z gate and absolute 1.5 margin,
  independent of adaptive knobs and moments. `WIN_GATE` logs mode, K, M, floor and fixed threshold at
  most once per 50 batches. WINNER, AMBIGUOUS and optional DIAG lines include mu/sigma.
- Tests cover independent candidate-by-candidate moment reconstruction, exclusion of all winning-ID
  deltas, population variance, ties/empty/single-ID inputs, gate boundaries, legacy override,
  environment validation, feature-off byte preservation, and relative 1e-3 GPU moment comparisons.
  Disabled Monte Carlo fixtures use the existing synthetic generator: four RX, rows 1/2/4/6/11/16,
  random 8–96-RB extents and start positions, 1–8 occasions, 1024 IDs, noise or full-band QPSK traffic
  with OAI `nr_gold_pdsch` type-1 DM-RS (port 1000, nSCID=0) on symbols 2/11,
  random DM-RS identity, four channel phases and independent AWGN. Data is random QPSK, not
  a channel-coded PDSCH transport block.
