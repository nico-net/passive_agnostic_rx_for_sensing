# UL-R2 — blind PUSCH grant solver

2026-10-08; `csd/ul-r2`; DGX GB10 aarch64 sandbox. The receiver has no gNB RRC input or radio access in this worktree. `ISAC_UL_PUSCH_SOLVER=1` enables this implementation; flag-off behavior remains on the existing path. The CSI-RS discovery interface contract in `nr_csirs_disc.h` is unchanged.

## Implementation

- **[CODE-READ + IMPLEMENTED]** `nr_pusch_solver.{h,c}` keeps an identity/epoch-keyed state per DL-locked C-RNTI. It admits only RV0, rank-one, one-code-block QPSK grants for a cheap LDPC/CRC probe. It walks U3's equal-length DCI 0_1 BWP/FDRA readings breadth first, then time-domain S/L/mapping, DM-RS positions/type/max length and ports, UL MCS tables including transform precoding, and data/DM-RS scrambling IDs. Dedicated DM-RS and data IDs are tried in isolation before the wider physical sweep. The RNTI's trusted DL MCS table, DL-derived IDs and first successful UL layout rank the search but never prove a hypothesis. U5's existing timing/CP search executes inside each probe.
- **[CODE-READ + IMPLEMENTED]** One nonzero CRC pass marks `CANDIDATE`; a second CRC pass on a different DCI payload and source slot with a compatible layout marks `SOLVED`. Later full PUSCH decodes use the solved interpretation and learn TDRA rows/layouts on each full CRC pass. The one-CB decoder checks segment and final TB CRC, and rejects the all-zero TB case. Probe calls suppress ordinary UL confirmation, identity learning and sensing observations.
- **[CODE-READ + IMPLEMENTED]** The bounded async queue drops before decode when the signal-time probe bucket (capacity four, refill one per 40 slots) or CPU-time bucket (200 ms burst, 250 µs refill per slot) is empty. Its counters expose grants, probes, probe CRC passes, candidates, solved UEs, full decodes, full CRC passes, drops and thread CPU per probe. No GPU allocation was added.
- **[CODE-READ, locations]** U3's equal-length catalogue export and hopping hypothesis are in `openair1/PHY/NR_UE_TRANSPORT/nr_pdcch_ul_config_disc.c:191,414`; solver admission/enumeration and two-pass feedback in `nr_pusch_solver.c:96,215,389`; worker reading grouping, probe/full decode and CPU accounting in `nr_pusch_passive_queue.c:108,211`; one-CB CRC and probe side-effect suppression in `nr_pusch_passive_decode.c:1698,1920`; periodic counters in `nr_pusch_passive_monitor_rt.c:259`. The U3/U5/DL paths are called through small hooks; `nr_csirs_disc.h` and the frozen sens6 fixtures are unchanged.

## False-accept bound and current gate

**[ANALYTICAL]** A single one-CB QPSK probe carries at least a 16-bit TB CRC, so a wrong fixed hypothesis has a one-pass candidate rate at most 2^-16 (about 1.53 × 10^-5) under uniform CRC syndromes. If wrong-hypothesis syndromes on distinct DCIs are independent, two passes for one fixed physical interpretation have probability at most 2^-32 (about 2.33 × 10^-10). With 279 probes in the final main replay, an overly conservative union bound over every unordered pair is 279 × 278 / (2 × 2^32) = 9.03 × 10^-6. The implementation permits far fewer pairs because it requires different DCI payload hashes and source slots, a common U3 layout, a DL-locked identity ticket and a nonzero TB. This is a conditional model, not an empirical false-alarm measurement: correlated interference and decoder bugs are excluded.

**[OFFLINE VERIFIED + INFERENCE]** The first PUSCH TB CRC milestone was not met on either final replay. The first unproved link is now the physical PUSCH interpretation and one-block LDPC/CRC pass: 279 main-capture and 190 older-capture hypotheses reached one-CB decoding but none passed CRC. The logs do not distinguish wrong FDRA/TDRA/k2, DM-RS or data scrambling, weak UL signal, and unmodelled UCI/PT-RS on the true grant; no one of these can be claimed as the cause without a CRC or independently validated UL IQ fixture. First-CRC latency is therefore unmeasured.

**[CODE-READ, scope]** U3 retains at most 64 equal-length layout options for a DCI length, and the queue probes at most two physical variants per job; the budget rotates this catalogue over later grants. A queued IQ snapshot uses U3's selected `k2`, so alternative `k2` values need a separate snapshot path. The solver currently searches no-UCI, no-PT-RS one-CB grants first. The existing receiver's optional UCI footprint recovery is available only when its separate `ul_uci_search` configuration is enabled; unknown ACK/CSI presence and beta-derived RE counts are not a solver dimension in these replays. There is no blind PT-RS parameter sweep in this decoder. These are remaining physical hypotheses, not evidence that any caused the observed CRC failures.
