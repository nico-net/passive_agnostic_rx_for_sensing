## Bottleneck analysis

[MEASURED, GB10, supplied by task, 2026-10-07] Before: approximately 69 ms GPU
per 64 snapshots, reported effective 0.053 TMAC/s; stage-2 score pass about
388 ms. Live capture every second DL slot drove 95% GPU utilization and starved
CSI-RS discovery. These are inherited observations, not rerun here.

[CODE-READ / ANALYTICAL] Let I=65,536, R=visible RBs, C=CSS0 RBs, D=capture
duration, S=retained snapshots, H=hypotheses, A=active snapshots, and
P=secondary-symbol surviving IDs. For the stream fixture R=217,C=6, one first
symbol has 651 distinct DM-RS REs, but the two sequence origins require
3(R+C)=669 pilot correlations per ID: **43,843,584 complex sign correlations**.
There are 207 valid six-RB windows per ID (CSS0 at RB0): **13,565,952 windows**.
An interior CSS0 exclusion removes another five windows. Every window and ID
still contributes exactly the same statistic; no new ID screen exists.

The old body expresses 87,687,168 int-to-float conversions, 175,374,336 sign
multiplications, and 175,374,336 correlation additions/subtractions per
snapshot, plus prefix updates, exclusion tests, denominator subtraction and
multiplication per window. These are source-level operation counts; the
compiler can predicate/fold some of them. Each ID also advances x1 even though
it is independent of the seed. Gold startup was already a 1600-bit jump and
continuation already wordwise: replacing bitwise generation was not available
as a speedup. `nid_best_symbol` performs per-pilot word-index/while checks and
shifts all prefix histories. The exact incumbent-bound test suppresses most
rounded divisions but does not suppress the full correlation.

[CODE-READ / ANALYTICAL] Dominant logical traffic/work by kernel, per captured
snapshot unless explicitly per pass. Bytes exclude cache-line rounding,
metadata, and allocator storage. Shared reads are logical thread reads, often
served by warp broadcast, **not DRAM traffic**.

For example ng=36,D=3,L=3 gives nb=216,M=832. The new score body evaluates
216 excesses rather than 1048 per hypothesis/snapshot, **4.85× fewer**; logical
prefix reads fall from 50,304 to 10,368 B, with 8384 B shared reads. This is an
operation reduction, not a claimed 4.85× runtime improvement.

The first-symbol sweep/store + standardize + accumulate minimum traffic is
about 3.25 MiB/snapshot including hit reads, before duplicated pilot loads and
history. Keeping all 65,536 scores in registers across the global median/MAD
barrier would require a different launch/synchronization/storage protocol.
Those host/launch changes belong to T24; this commit retains the exact global
calibration and its coalesced score stores. The existing SWEEP event bucket
also includes `calibrate`/`combine`; use nsys for individual kernel timings.

The benchmark's explicit useful-work numerator is I·3R·64 = 2,730,491,904 at
217 PRB. With that definition, 69 ms means **0.0396 TMAC/s**, not 0.053, and
0.5 TMAC/s requires **≤5.461 ms**, stricter than 7 ms. Do not mix differently
counted inherited TMAC/s with this reproducible numerator. Benchmark acceptance
checks both ≤7 ms/64 and ≥0.5 TMAC/s, plus every kernel <5 ms.

## Changes and exactness

- `nr_pdcch_nid_stage1.h:32`: prepared `r+i`/`r−i` pilot pairs. Both fit exactly
  in binary32 even at int16 extrema; bit-driven selects/sign flips replace
  repeated conversions and multiplications. Reconstructing I/Q for power is
  also exact. Correlation still adds REs, RBs, and prefixes in oracle order.
- `nr_pdcch_nid_stage1.h:48`: one shared denominator/exclusion array per region
  and block. Its six-value power-prefix history matches the original full
  prefix array, including float rounding. No reciprocal approximation.
- `nr_pdcch_nid_stage1.h:79`, `nr_pdcch_nid_gpu.cu:74`: x1 words shared across
  all IDs in the tile. Three x2 words cover 16 RBs; unrolled extraction uses
  constant shifts and no per-RE while loop. All IDs retain all pilots/windows.
  Rounded incumbent-bound divisions and final sqrt are unchanged; CUDA retains
  `--fmad=false`, precise division/sqrt and no fast math.
- `nr_pdcch_nid_gpu.cu:399`: one warp per active snapshot caches exact FP64
  excess per logical bundle. All aggregation levels and consistency votes
  reuse it. Candidate sums are **not** formed from lower-AL sums. Warp reduction
  only chooses maxima with the original AL/CCE tie ordering; the control lane
  adds snapshot scores in the original order. Prefix/power precision is intact.
- `nr_pdcch_nid_occupancy.h`, `nr_pdcch_coreset_map.c:456,481`: allocation-free
  capture gate on the existing frequency-domain symbol; no IQ copy. Complete
  six-RB groups use all 54 **non-DM-RS** REs, excluding groups overlapping CSS0.
  uint64 energy sums include int16 extrema safely; the ARM NEON reduction is
  integer-exact. Other architectures retain the scalar implementation.
- `nr_passive_metrics.{h,c}`, `nr_passive_metrics_json.c`: relaxed atomic capture
  counters; noise dB conversion stays in the metrics reader, off the RT path.
  JSON appends `nid_capture_offered`, `nid_capture_taken`,
  `nid_capture_skipped_empty`, `nid_capture_noise_floor_db` once offers exist.
  `taken` means producer accepted; offered−taken−empty includes queue/validation
  refusals. Noise is mean complex sample power in ADC-unit², not dBFS.
- Stream benchmark now prints calls/total/peak for every existing kernel bucket
  and enforces the T25 timing targets. No production timing or submission code
  changed. All `.cu` edits are confined to `sweep`/`score` bodies and their
  explanatory comment; signatures, `first,count`/`base,count`, block dimensions,
  grid meanings, allocation, worker, bank and thread-affinity code are unchanged.
- One pre-existing full-build blocker was fixed in
  `tests/nr_gpu_fep_hygiene_test.cc:125`: test stub now has the C linkage of its
  existing declaration. No production GPU hygiene implementation changed.

## Capture flags and false-alarm calibration

| Flag | Default | Meaning |
|---|---|---|
| `ISAC_PDCCH_NID_GPU_SYMBOLS` | **3** | Existing live incremental rotation starts at 0,1,2; explicit 0 retains all symbols. This is a configurable search scope, not a claim that all NR CORESETs start before symbol 3. |
| `ISAC_PDCCH_NID_GPU_OCC_GATE` | **1** | 0 bypasses occupancy selection; every offered snapshot still receives the full original score. |
| `ISAC_PDCCH_NID_GPU_OCC_DB` | **6** | Accept if any outside-CSS0 group exceeds the floor by ~4×. Margin over 54-RE noise averages avoids capturing routine noise fluctuations; weak traffic is still probed by the floor. Valid 0..60, malformed/nonfinite uses 6. |
| `ISAC_PDCCH_NID_GPU_OCC_FLOOR_PCT` | **10** | 1..100; invalid uses 10. Exactly this many unconditional positions in each complete block of 100 offers **per start symbol**, with block-dependent permutation to avoid fixed periodic aliasing. |

Noise estimate = 20th percentile of unmasked complete groups, EMA attack 1/16,
decay 1/4. Compare against max(current percentile, EMA) so a noise/gain increase
cannot make every group appear occupied during attack. Geometry/PCI/duration
changes and acquisition sync losses reset the per-symbol state. An all-band
occupancy or a badly biased floor can suppress energy-based admission; the
unconditional floor remains. Skipped starts still advance the existing symbol
rotation. No new switch depends on `ISAC_CSIRS_DISC`.

[ANALYTICAL, inherited null assumptions] Unlike a DM-RS-energy gate, this gate
reads RE indices 0,2,3 modulo 4, while stage 1/2 read 1 modulo 4. Under the
existing independent circular-noise null, conditioning on the former does not
condition the scoring samples, even if the floor is estimated from past data.
The floor schedule also does not inspect scores or IDs. Therefore the retained
null statistics have the same distribution; **no inverse sampling weight or
lowered score threshold is justified**. Multi-symbol calibration still uses its
fixed, ID-independent panel and the original per-symbol z>2 requirement.

`standardize` calibrates every captured snapshot across the complete ID
population. `family_totals/thresholds` estimate lambda from retained *actual*
hits per duration/start, not elapsed slots or offered counts. The family count
remains all legal symbols/durations (conservative when only three starts are
captured). T22's lifetime alpha spending `0.01/(t(t+1))` still counts every
completed look including wraps; skipping empty snapshots does not refund it.
The publication/decoy/paired-t tests are unchanged. Thus the inherited nominal
false-record bound is not increased by this capture selection under that null.

As in T19/T22, plug-in Poisson lambda is **not a proof for arbitrary structured
or correlated interference**. No empirical OTA false-record rate is claimed;
negative-stream calibration and real RT timing remain device/OTA acceptance.
The CPU regression verifies that replacing every scoring RE with full-scale IQ
leaves gate decisions and tracked floors exactly unchanged over 1000 noise
snapshots; only 100 unconditional snapshots are accepted.
