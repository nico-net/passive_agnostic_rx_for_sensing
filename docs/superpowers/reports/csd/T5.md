# T5 — U5 fully blind CSI-RS discovery integration

Host: DGX aarch64, worktree `rr-csd-a`, branch `csd/t5`. No receiver, raw replay, OTA run, or GPU unit test was executed.

## Outcome

[OFFLINE VERIFIED] `ISAC_CSIRS_DISC=1` now connects the U1 ring worker to one U2 detector call per batch, U3 legal-row
hypotheses, and the U4 ID/slot-number sweep. The detector uses `min_strength=1.03`; the pipeline admits only winners with
`z >= 4` and `z - z_second >= 1.5`, appends them under the CSI-RS state lock, seeds their measured period/offset and
`slot_delta`, and confirms them from the all-DL-slot PDSCH hook. Confirmed resources are no longer re-swept.

[OFFLINE VERIFIED] Discovery confirmation scores only the candidate RB extent and averages per-port correlation
magnitudes across all four RX branches non-coherently. Legacy IDSWEEP is disabled in discovery mode. The PDCCH occasion
path does not call the confirmer when discovery is enabled, so `ISAC_PDCCH_SCAN_EVERY_SLOT` is not required and scoring
is not duplicated. A nonzero sweep `slot_delta` is applied both during confirmation reference generation and later
sensing/CFR capture.

[OFFLINE VERIFIED] Confirmed NZP resources are exported through bounded, mutex-protected dynamic CSI-RS monitor entries,
including geometry, extent, scrambling ID, period/offset (including two-phase confirmations), and slot delta. Dynamic
entries are removed on revocation or epoch reset without changing manually configured monitor ownership. Existing
rate-matching export continues to read the confirmed banks.

## Implementation

- `nr_csirs_disc.c`: installs the U1 process hook before ring allocation; calls `nr_csirs_disc_detect()` exactly once;
  builds bounded union views needed by multi-symbol/CDM rows; filters already-confirmed geometry; sweeps the top
  hypotheses (default 32); performs GPU-to-CPU batch fallback; logs `FOOTPRINT`, `HYPOTHESES`, `WINNER`, and `AMBIGUOUS`;
  resets detector/confirmation/monitor/ring state on epoch changes.
- `nr_csirs_disc_backend.c`: loads both `libcsirs_disc_gpu.so` and `libnr_csirs_disc_gpu_sweep.so` into one public ops
  table, installs the unified allocator pair before the ring is allocated, honors
  `ISAC_CSIRS_DISC_BACKEND=auto|cpu|gpu`, and uses a shared exponential breaker around GPU failures.
- `nr_csirs_blind_rt.c` and `nr_csirs_blind_search.{h,c}`: thread-safe winner admission, seeded phase confirmation,
  slot-delta propagation, extent-limited four-RX scoring, discovery-only empty candidate banks and IDSWEEP suppression,
  per-DL-slot due scoring, and dynamic monitor add/remove on confirmation/revocation. Feature-off keeps the legacy
  four-reference-plane/antenna-0 path and its existing candidate rotation.
- `nr_csirs_monitor.{h,c}`, `csi_rx.c`, and `phy_procedures_nr_ue.c`: thread-safe runtime add/remove/all APIs, stable
  per-thread due snapshots, phase-preserving entries, shifted sequence generation, every-symbol FEP for the discovery
  ring, and confirmation from the PDSCH receive hook.
- `nr_pdcch_blind_monitor_rt.c`: suppresses the old occasion-scoped confirmation call only when discovery is enabled.
- `nr_passive_metrics*`: exports `csirs_disc_{batches,footprints,hyps,winners,ambiguous,feed_drops,gpu_batches,
  cpu_batches,batch_us}` through the existing `ISAC_METRICS` JSON snapshot.
- `nr_csirs_disc_e2e_test.cc` and the RT bridge: mixed rows 1, 2, 4, 6, 11, and 16 on a 217-RB, four-RX, 10 dB grid
  with full PDSCH load, DM-RS, and SSB; exact geometry/ID/period/offset confirmation; DM-RS-only negative case. Row 1 is
  density 3, RB `0:52`, ID 415, period 10. The existing generator's default channel remains unchanged; only this mixed
  integration fixture opts into its deterministic full-rank port channel.

The worker currently has no stable slot-dependent exclusion contract for the receiver's known SSB REs and CORESET#0
occasion symbols. The blind monitor and frame parameters know those facts in their own execution contexts, but exporting
an incomplete static mask to the asynchronous batch worker would exclude the wrong slots. Therefore U5 passes no
structural exclusions and relies on U2's intrinsic slow-time periodicity test. This is explicit, not an assumption that
SSB/CORESET are unknown.
