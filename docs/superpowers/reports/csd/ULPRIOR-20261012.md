# ULPRIOR-20261012: UL BWP start by prior-ranked provisional adoption (branch csd/ul-prior, from csd/otatest be73cf38f5)

Host: DGX GB10 aarch64, CUDA build `build_t26`, 4 RX, builds/replays via heavy.sh, one at a time, no OTA/capture/UHD. Labels: [UNIT-TESTED, DGX] / [MEASURED replay, DGX] / [DERIVED] / [INF]. Captures never merged.

## Mechanism (`ISAC_UL_LOCK_PRIOR_SEARCH=1`, default off, needs `ISAC_UL_LAYOUT_LOCK=1`; off = old code path)
- Priors: (a) SIB1 initialUplinkBWP (start/size); (b) DL-consistent start (`cfg->bwp_start` of the DL BWP, new field `nr_ul_layout_cell_t.dl_bwp_start`, used only with `dl_bwp_size>0`). Only a STARTING POINT.
- Hypotheses: `append_prior_locked()` adds (N, start) for starts prior +-0..4, sizes {SIB1 size, DL size, 3 largest N the RIV fit allows}, subject to riv_bits(N)=fitted width, N(N+1)/2 > max observed RIV, start+N <= carrier (<= 96 added; re-run at each demotion for late priors).
- Rank key (smaller better): size class (SIB1 size, DL size, other) first, then start distance to the nearest prior, SIB1 before DL, larger N. Size first because size is the well-determined part; start is what is searched.
- Provisional adoption at the FIT: top hypothesis becomes the locked layout at once (PUSCH decode runs), log `PRIOR_ADOPT`. Every 4th DCI is a DM-RS probe so votes keep accumulating; a normal vote lock (LOCK_MIN 6, ratio 2, 2 RNTIs) confirms or MOVES the adoption; a CRC-first trial pass also confirms/moves it.
- Confirm: TB CRC pass under it (CRC24A/multi-segment: at once; CRC16: the existing CRC_GUARD rule, passes>=2 from >=2 slots, Poisson p<0.01, when `ISAC_UL_LOCK_CRC_GUARD=1`; else one pass).
- Demote: only CRC-EXPECTED failures count. A decode is expected to pass when decoder `snr_db >= 10log10(2^SE - 1) + 2 dB`, SE = TB bits per coded RE (TBS*Qm/G), i.e. BLER < ~50 % [INF, gap is an LDPC short-block rule of thumb]. Dwell D = 10 (`ISAC_UL_LOCK_PRIOR_DWELL`): D expected failures with 0 passes demote (true hypothesis fails 10 in a row with p < 1e-3 [DERIVED]); 4D expected with < 2 passes also demote. Low-SNR grants are never evidence, so at this site (CRC ~0 for SNR) nothing cycles.
- Bound: at most 16 hypotheses tried, then back to the top prior and the search stops (`PRIOR_EXHAUSTED`). Limit: the SNR is measured by the decoder under the hypothesis it decodes, so a far-wrong start reads noise and is not demoted by CRC; the DM-RS votes are the only cure there.
- STATS: `bwp=PROVISIONAL|LOCKED ...` and `prior[prov= src=sib1|dl|neighbour hyp= crc_expected_n= crc_ok= dec= demotions= done=]`. Logs `PRIOR_ADOPT/DEMOTE/CONFIRM/EXHAUSTED`.
- Not combined with `ISAC_UL_LOCK_SPRT/EDGE/COHERENT` (their lock requires an unlocked state).
- Files: nr_pdcch_ul_layout_lock.[ch], nr_pusch_passive_queue.c (verdict hook), nr_pdcch_blind_monitor_rt.c (dl_bwp_start).

## Unit tests [UNIT-TESTED, DGX] `UlLayoutLock.PriorSearchStaysMovesAndIgnoresLowSnr` (UlLayoutLock* 9/9 pass)
prior right (216@1) -> adopted, confirmed, stays through 300 expected failures after confirmation; prior wrong (SIB1 216@1, truth 216@0 = the DL start) -> exactly 1 demotion, moves to 216@0, confirmed; low-SNR grants (800, nothing expected) -> 0 demotions, stays on the prior; nothing ever passes with all grants expected -> exactly 16 demotions, back to the top prior, stops; `prior_expected` threshold checks.

| raw_pci923_tim_12s_tile3 (SSB 233, no fixture) | SIB1 0@217 and DL 0@217 | 217@0 (src=sib1) | 0.96 s | 0 | 0 / 234 | none | TIM 107@5 / 107@2 |
Reading: provisional lock is immediate (about 1-2 s) so UL decoding starts at once, but BOTH adoptions are wrong (truth 216@1 and 107@x) and neither moved: SNR is so low that almost no decode is CRC-expected (crc_ok 0 on all 2132 decodes), exactly the designed no-cycling behaviour, but it also means CRC cannot correct the prior here. On b the weak votes already point at 216@1 (the earlier answer) yet stay below LOCK_MIN/ratio. Prior sizes 217/217 (TIM) are far from 107, and the size classes rank 217-class and 216/215 before 107 at any start, so 107@x is out of reach of the 16-hypothesis search: size needs its own estimate from RIV statistics (follow-up; not built).
Verdict: mechanism works as specified and is safe (no false lock, bounded), but on these two low-SNR captures it provides a provisional layout, not a correct one. Do not expect correct decoding from the prior alone; a fixed truth is never assumed.
