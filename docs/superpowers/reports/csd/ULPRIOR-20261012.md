## Mechanism (`ISAC_UL_LOCK_PRIOR_SEARCH=1`, default off, needs `ISAC_UL_LAYOUT_LOCK=1`; off = old code path) -- revision 2 (size from the RIV fit)
- SIZE comes from the layout lock's RIV-statistics fit, never from a prior: the fit's candidate N (cand_list sizes whose riv_bits equals the fitted width of a prefix) that decode all but 1 % of the bank's CRC-verified RIVs to legal (S, L). Class = rank of the admitting prefix (twins 217/216/215 share a class). A prior size not in this list (217 initial BWP vs a 107 dedicated BWP) is never adopted; no fitted size -> nothing is adopted.
- START seeds (only the start): SIB1 start and DL-consistent start (`nr_ul_layout_cell_t.dl_bwp_start`), each clamped into [0, carrier-N], then left edge, carrier centre, right edge; then +-1..8 around every seed (+-2 for sizes after the first). Hypotheses are added before the legacy list (<= 120).
- Rank key: size class (a size with >= 3 summed DM-RS votes jumps ahead, most votes first), start distance to nearest seed, seed order, SIB1/DL size, larger N.
- Provisional adoption at the FIT (layout locked at once, PUSCH decodes run, `PRIOR_ADOPT`). Every 4th DCI is a DM-RS probe so votes keep accumulating.
- Votes move it (`PRIOR_VOTE_MOVE`): hypothesis level = leader != current with >= 3 votes and >= 2x the votes of every other hypothesis; size level = the fitted size with >= 3 summed votes and >= 2x every other size replaces a different current size (best seed-ranked start of that size). A full vote lock (6 votes, 2x, 2 RNTIs) or a CRC-trial pass confirms/moves as before. Bound rationale [INF]: control-like false votes are rare and spread over hypotheses; a move only changes a provisional guess.
- Confirm: TB CRC pass under it (CRC24A/multi-segment at once; CRC16 via CRC_GUARD, passes>=2 from >=2 slots, Poisson p<0.01).
- Demote (kept): only CRC-EXPECTED failures count. Expected = decoder `snr_db >= 10log10(2^SE - 1) + 2 dB`, SE = TB bits per coded RE [INF]. D = 10 expected failures with 0 passes (p < 1e-3 for a true hypothesis [DERIVED]) or 40 with < 2 passes -> next ranked hypothesis. At most 16 tried, then back to the top prior and stop (`PRIOR_EXHAUSTED`). Limit: the SNR is measured under the decoded hypothesis, so a far-wrong start is not demoted by CRC.
- STATS: `bwp=PROVISIONAL|LOCKED` and `prior[prov src=sib1|dl|geometry|neighbour hyp crc_expected_n crc_ok dec demotions done]`; PRIOR_ADOPT prints the fitted sizes. Not combined with SPRT/EDGE/COHERENT.
- Files: nr_pdcch_ul_layout_lock.[ch], nr_pusch_passive_queue.c (verdict hook), nr_pdcch_blind_monitor_rt.c (dl_bwp_start).
