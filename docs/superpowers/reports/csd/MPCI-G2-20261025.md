# MPCI G2 (code): SM partition from the derived plan; nID/check cores from the core layout (2026-10-25)

Branch mpci/g-g2 from mpci-main 1dc62a8d3c. No receiver run, no OTA, no timing.

## Changes
1. `nr_gpu_green.h`: includes `nr_gpu_sm_plan.h`. After `all` is read, the granularity is queried with a SplitByCount of minCount 1 (query only, creates nothing; group size = granularity), the plan is computed (SM count, granularity, green=1, tier SHARED/DISCRETE from `cudaDevAttrIntegrated` -- `nr_gpu_platform_probe` is not linked into every CUDA library, so it is not called here). `sms` (the discovery request) = `plan.disc_sms`; `if (part[1].sm.smCount >= 32)` -> `if (plan.split2)`; literal group request 4 -> `plan.group_req`. Driver checks (`rc`, `g < 16`, `g >= disc_n+1`, groups==1) are kept; a driver result that differs from the plan prints `[GPU] SM plan mismatch: ...`. New startup line `[GPU] SM plan: ...` (shows reason `no_green` / `no_rt_sms` / `no_gpu` too).
2. `nr_pdcch_nid_gpu.c`: default core = the layout's nID role (`nr_core_layout_env_default("ISAC_PDCCH_NID_GPU_CORE")`, "-1" = highest CPU of the lane) when a plan is active; legacy 13 only when no plan (ISAC_CORE_PLAN=0). Weak-symbol guard (unit tests link without the utils library). The env key, when set (the plan exports it), still wins.
3. `nr_pdsch_gpu_demod_host.c` (`nr_bgq_start`): default check cores = the layout's `ISAC_GPU_CHECK_CORES` mask (empty = unpinned) when a plan is active, legacy "10-14" only without a plan.
4. `executables/nr-uesoftmodem.c`: in the existing `--passive-rx` defaults block, `setenv("CUDA_DEVICE_MAX_CONNECTIONS", conn, 0)` (grep: before this only env files / p99_replay_clean.sh set it, no source did). conn = next power of two >= 3 x `NR_GPU_PASS_RING` (7 instances = 4 DL + 2 UL + 1 probe, nr_pdsch_gpu_fep.h; 3 streams each: s, s2, s_lo, nr_gpu_pass_graph.cu alloc_inst) = 21 -> 32, clamped [8,32] (CUDA maximum 32). Operator value kept. No new flag.
5. Test `openair1/PHY/TOOLS/tests/test_nr_gpu_green_g2.cpp` (target in `cmake_targets/mpci_gpu.cmake`, block `# ---- G2 ----`): fake driver replay of the green.h sequence with the plan's requests; 48 SMs/gran 8 gives disc 8, rt 40, group_req 4, group 8, DL 32, UL 40, probe 8 (the old literal result); driver == plan over SM 8..160 x gran {1,2,4,8}; old rt>=32 rule agrees on gran-8 devices; connection derivation.
