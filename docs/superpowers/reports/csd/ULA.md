# UL-A: bounded UL pipeline and per-UE UL state (U1, U4)

2026-10-08. Branch `csd/ul-a`, based on `csd/ulbase`. Scope: ULSCOPE T25 and T28. All new runtime behavior is behind `ISAC_UL_PIPELINE=1` or `ISAC_UL_UE_STATE=1`; both default off.

## Implementation

- **[CODE-READ]** `executables/nr-uesoftmodem.c:217,309,611` starts one UL consumer and prewarms its decode context, IQ snapshot, CFR scratch, and UCI scratch before RX start. The core planner reserves one PUSCH role. Failed prewarm closes admission. The raw-IQ EOF shutdown callback joins the consumer.
- **[CODE-READ]** `nr_pusch_passive_queue.c:143,203,298`, `nr_pusch_passive_queue_cursor.h:1`, and `nr_pusch_passive_decode.c:515,538` implement a depth-2..64 ring with drop-oldest on full, epoch rejection, wrap-aware freshness with a five-slot margin, a private IQ copy before decode, and drop counters. Shutdown discards queued work; admission is rechecked under the lock. One flagged consumer uses at most four antenna snapshots, each preallocated for a subframe plus 8192 samples, and fixed CFR/UCI scratch. No inline heavy fallback runs on the flagged RT path. The legacy path retains its lazy/inline behavior.
- **[CODE-READ]** `nr_passive_ue_ctx.c:292,372,646,675` holds UL DCI length/layout, BWP, TDA/k2, DM-RS and data IDs, TA, and CFO for each DL-locked C-RNTI. Values carry unknown/DL-prior/provisional/TB-confirmed provenance. Trusted DL length/BWP and measured DL CFO seed priors before the first UL grant. Grant and delayed TB feedback carry identity generation, incarnation, and configuration epoch. Hard reverify clears old UL values, and RNTI reuse creates fresh state. Verified RAR and TA MAC CE updates feed timing. State-only mode discards JSON output to `/dev/null`.
- **[CODE-READ]** `nr_pusch_passive_ul_ids.c:72` and `nr_pdcch_blind_monitor.c:5183` use a fixed 64-UE ID table. PCI, the UE's PDSCH scrambling ID, and its PDCCH ID rank first as hypotheses; only a successful nonzero TB CRC confirms the IDs used. Old tickets cannot confirm a new UE incarnation. The flagged UL decode path no longer uses the cell-global ID estimator. U4 admission requires the DL context's trusted DCI-length lock.
