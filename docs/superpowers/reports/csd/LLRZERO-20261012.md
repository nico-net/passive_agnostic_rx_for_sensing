# LLRZERO (2026-10-12): 2-layer exact-zero LLRs -- STATUS: REAL quantisation effect (weak-layer rounding), fix = ISAC_L2MAXH_DELTA_NL2, default off, CRC benefit not proven

Host DGX GB10 aarch64, worktree rr-csd-llz (csd/llr-zero from csd/otatest 62b7afc62d). No OTA/capture/UHD.

## Verdict: the exact zeros are REAL (not GPU, not CSI-RS erase) and are an int16 resolution effect of the 2-layer mode-2 equaliser; they are not singular/w==0 REs. Lowering log2_maxh by 3 for nl>=2 removes ~80 % of them; the 2-layer CRC gain is small and within run noise.
- [CODE-READ] nr_dlsch_mmse mode 2 rounds w = 1/[G^-1]_ll and z = w*x to int16 in |h|^2>>log2_maxh units; log2_maxh is sized from the MEAN |h| (see the ISAC_L2MAXH_DELTA comment: "equaliser output sits at a few LSB"), so a layer 15-20 dB below the strongest has w of a few LSB: z and mag round coarsely, mag=lround(0.63 w) can be 0. A genuine exact-zero source also exists: singular branch (|pivot|<1e-9) and dinv<=1e-12 give w=0 -> z=mag=0 -> all LLRs of that RE 0.
- [CODE-READ] A common output gain does NOT recover resolution already lost upstream: G and H^H y are int16 after >>shift. If the diagnostic shows w small, ISAC_L2MAXH_DELTA<0 is the more direct lever (existing flag; arm to run).

## What is committed (all default off, CPU path)
- ISAC_MMSE2_DIAG=1 (needs ISAC_PDSCH_RM_GENIE=1 and CPU demod, ISAC_PDSCH_GPU_EXACT_DEMOD=0): log `MMSE2DIAG rnti fs crc mcs nl Qm shift gain_k layers: [w z w0 z0 mag0 sing sat]` per layer (mean w, mean |z|, % w==0, % z==0, % mag==0, % singular, % saturated).
- ISAC_PDSCH_MMSE2_GAIN=N (0 = off, exact): common gain 2^k, k = clamp(N - log2_maxh, 0, 12), per grant (log2_maxh is per grant), multiplies w before z, mag, magb, magr of all layers alike. Saturation is clamped by the existing QF_S16. NOT mirrored in the GPU k_llr/re_mmse2 path and NO unit test yet (only worth doing if the diagnostic shows the weak-layer rounding is real).
- tests/passive_rx/timacq_replay.sh: `TMO` env overrides the 3600 s hard timeout (default unchanged).

Nl=1 zero% is 0.4-5 % in all arms (unaffected). MCS 10+ 2-layer: CRC ~0 in every arm, before and after.
- GPU vs CPU: identical zero% -> not a GPU artifact. FULL_ERASE 0 vs 1: identical -> not CSI-RS erasure.
- MMSE2DIAG (CPU, 2L, MCS 0-9): mean w = 62 / 30 (tile3 layers 0/1), 220-250 / 76-90 (b); % w==0 or z==0 only 0.1-0.9 %, % singular 0. The zero LLRs are therefore not from w==0: z is only 14-120 LSB, the weak layer half the strong one, and the LLR/int8 stage rounds small |z| to 0. With DELTA -3: w = 470-670 / 210 (tile3), 1800-2400 / 600-700 (b), zero% 24 -> 4 and 8 -> 3. GAIN=14 (CPU only, applied after the int16 rounding of G and H^H y) gets zeros down as well but w saturates (2000-5500) and CRC does not improve.
- 2-layer exact zeros are layer-dependent in the sense that the weak layer's w is ~2-3x smaller; RMMAP zero% is per grant (both layers).

## Fix (default off)
ISAC_L2MAXH_DELTA_NL2=N: adds N to log2_maxh for nl >= 2 only (CPU nr_dlsch_demodulation.c and GPU refuse() -> l2_delta, same path as ISAC_L2MAXH_DELTA). GPU CHECK=1 (bit-exact vs CPU loop, 114+1000+100+6001 grants, 4 runs, both captures): check_bad=0. No separate ctest unit test (the GPU CHECK on real grants is the bit-exact test). MMSE2_GAIN stays CPU-only and is NOT recommended.
Not claimed: a CRC gain. CPU pooled +9 pts tile3 / +3 pts b, GPU (CHECK slows it) -2 / -3 pts, run-to-run spread similar (e.g. b DELTA_NL2 25-41 %). Needs OTA A/B or a longer replay set before default-on.
