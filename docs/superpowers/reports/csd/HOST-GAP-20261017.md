## What it does
NEON sign-mask unscramble (same ceil(G/32) words); deinterleave vld2/3/4 + uzp for Qm 2/4/6/8 (falls back if E % Qm != 0); rate-match RX contiguous vaddq_s16 runs with identical order, filler skip, ring wrap and int16 wraparound; int8 pack straight from d (no z buffer) when C != 0, d_to_be_cleared, Foffset <= Ncb, E % Qm == 0, else original. No parallel segments. LLR stats loop unchanged (cheap, feeds EVMGRANT/LLR fields).
